Windows’ta kurulum

Son güncelleme: 4 Ekim 2026

PanelDeck’in Windows programı ücretsizdir ve Windows 10 ile 11’de (64 bit) çalışır. Kurulum yönetici izni istemez; program yalnızca sizin kullanıcı hesabınıza kurulur.

1. İndirin

⬇ PanelDeck-Kurulum.exe

Dosya her zaman GitHub’daki resmî sürüm sayfasından iner. Başka sitelerdeki kopyaları kullanmayın. Tarayıcınız dosyanın “yaygın olarak indirilmediğini” söylerse, indirilenler listesinde dosyanın yanındaki menüden dosyayı saklamayı seçin.

2. “Windows kişisel bilgisayarınızı korudu” uyarısı çıkarsa

Kurulum dosyasını açtığınızda mavi bir Microsoft Defender SmartScreen penceresi çıkabilir. Devam etmek için:

  1. Penceredeki “Ek bilgi” bağlantısına tıklayın (bazı Windows sürümlerinde adı “Daha fazla bilgi”dir).
  2. Yayımcı “Bilinmeyen yayımcı” olarak görünür. Alttaki “Yine de çalıştır” düğmesine basın.

Bu uyarı neden çıkıyor?

SmartScreen, Windows’un henüz tanımadığı ve ücretli bir kod imzalama sertifikasıyla imzalanmamış programlarda bu uyarıyı gösterir. PanelDeck yeni bir program ve kurulum dosyası şimdilik imzasız. Uyarı, dosyada virüs bulunduğu anlamına gelmez; yalnızca Windows’un bu dosyayı henüz tanımadığını gösterir. Her yeni sürüm yeni bir dosya olduğu için uyarı güncellemelerden sonra yeniden çıkabilir.

Dosyayı doğrulayın (isteğe bağlı)

Her sürümün notlarında kurulum dosyasının SHA-256 özeti (“sha256”) yazar. Elinizdeki dosyanın bizim yayınladığımız dosya olduğunu şöyle kontrol edebilirsiniz:

  1. Başlat menüsüne “PowerShell” yazıp açın.
  2. Şu komutu yapıştırıp Enter’a basın (dosyayı başka bir klasöre kaydettiyseniz yolu değiştirin):
    Get-FileHash "$env:USERPROFILE\Downloads\PanelDeck-Kurulum.exe"
  3. Çıkan “Hash” değerini son sürümün notlarındaki sha256 değeriyle karşılaştırın. Büyük-küçük harf farkı önemli değildir; değerler aynıysa dosya değiştirilmemiştir.

Kurulumdan sonra

  • Program, telefonu bağlamanız için sizi adım adım yönlendirir; telefon uygulamasını programdaki QR koduyla indirebilirsiniz.
  • Kablosuz bağlantı için Windows Güvenlik Duvarı bir kez izin sorabilir: “Özel” ve “Ortak” ağların ikisine de izin verin.
  • Antivirüs programınız PanelDeck’i yanlışlıkla engellerse lütfen bize bildirin.
  • Kaldırmak için: Windows Ayarlar → Uygulamalar → PanelDeck → Kaldır.

Installing on Windows

Last updated: 4 October 2026

PanelDeck’s Windows program is free and runs on Windows 10 and 11 (64-bit). The installer doesn’t need administrator rights; the program is installed only for your own user account.

1. Download

⬇ PanelDeck-Kurulum.exe

The file always comes from the official release page on GitHub. Don’t use copies from other sites. If your browser says the file “isn’t commonly downloaded”, choose to keep it from the menu next to the file in the downloads list.

2. If “Windows protected your PC” appears

When you open the installer, a blue Microsoft Defender SmartScreen window may appear. To continue:

  1. Click the “More info” link in the window.
  2. The publisher shows as “Unknown publisher”. Click the “Run anyway” button at the bottom.

Why does this warning appear?

SmartScreen shows this warning for programs that Windows doesn’t recognize yet and that aren’t signed with a paid code-signing certificate. PanelDeck is a new program and its installer isn’t signed yet. The warning doesn’t mean a virus was found; it only means Windows doesn’t know this file yet. Each new version is a new file, so the warning may come back after updates.

Verify the file (optional)

The notes of every release list the installer’s SHA-256 checksum (“sha256”). To check that your file is the one we published:

  1. Type “PowerShell” in the Start menu and open it.
  2. Paste this command and press Enter (change the path if you saved the file somewhere else):
    Get-FileHash "$env:USERPROFILE\Downloads\PanelDeck-Kurulum.exe"
  3. Compare the “Hash” value with the sha256 in the notes of the latest release. Upper and lower case don’t matter; if the values match, the file hasn’t been changed.

After installing

  • The program guides you step by step to connect your phone; you can get the phone app from the QR code inside the program.
  • For the wireless connection, Windows Firewall may ask for permission once: allow both “Private” and “Public” networks.
  • If your antivirus blocks PanelDeck by mistake, please let us know.
  • To uninstall: Windows Settings → Apps → PanelDeck → Uninstall.

Microsoft Store

A Microsoft Store version of PanelDeck is being prepared. Once it’s out, we recommend installing from there: the Store version is checked by Microsoft, updates arrive automatically and there is no SmartScreen warning.
