📲 Установка и подключение

Установите программу и приложение, затем подключите телефон по QR-коду.

PanelDeck состоит из двух частей: программы для Windows и приложения для Android. У обеих должна быть одна и та же версия; программа сама находит новые версии.

1. Установите программу на ПК

  1. Скачайте и запустите установщик PanelDeck. Права администратора не нужны.
  2. Если Windows пишет, что «защитила ваш компьютер», нажмите Подробнее → Выполнить в любом случае. Подробности в руководстве по установке.
  3. При первом запуске программа открывает мастер Подключите телефон.

2. Установите приложение на телефон

  1. Отсканируйте код загрузки в мастере камерой телефона.
  2. Нажмите на загруженный файл UsbDeck.apk.
  3. Если Android спросит, включите Разрешить установку из этого источника и нажмите Установить. Режим разработчика не нужен.

3. Свяжите их (Wi‑Fi, рекомендуется)

  1. Убедитесь, что ПК и телефон подключены к одной сети Wi‑Fi.
  2. Откройте PanelDeck на телефоне, нажмите Подключиться по QR-коду и отсканируйте код на ПК.
  3. Нажмите Связать. Если брандмауэр Windows спросит, разрешите и «Частные», и «Общедоступные» сети.

Чтобы позже снова открыть мастер, нажмите кнопку ＋ Добавить телефон на верхней панели программы.

Подключение по USB (для опытных)

Для подключения кабелем в параметрах разработчика на телефоне должна быть включена Отладка по USB. Раздел USB в мастере показывает шаги и состояние подключения в реальном времени.

Вне дома

После сопряжения телефон подключается и через мобильный интернет, если общего Wi‑Fi нет; ничего настраивать не нужно, соединение защищено сквозным шифрованием. Подробности в руководстве «Второй экран и удалённое подключение».

Для первой раскладки выберите «Стример», «Геймер», «Офис» или «Вождение грузовика» в меню Профиль → Готовые макеты…; настоящие логотипы ваших программ добавятся автоматически.
