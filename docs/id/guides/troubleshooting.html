🛠️ Pemecahan masalah

Solusi cepat untuk koneksi, versi, ETS2, OBS, dan Discord.

Ponsel tidak terhubung

  • Apakah PC dan ponsel berada di Wi‑Fi yang sama? Jika tidak, ponsel terhubung dari jarak jauh lewat data seluler, yang bisa memakan beberapa detik.
  • Di program, Akses nirkabel (Wi‑Fi) di jaringan yang sama harus aktif (kartu Pengaturan → Koneksi nirkabel).
  • Jika Windows Firewall bertanya, izinkan jaringan “Pribadi” dan “Publik”.
  • Pindai kode QR lagi: di ponsel, ⋯ → Pindai kode QR.
  • Ponsel hilang? Di program, Pengaturan → Perbarui kunci pemasangan. Pemasangan lama berhenti berfungsi.

Peringatan “Versi tidak cocok”

Perbarui program PC dan aplikasi ponsel ke versi yang sama. Program menemukan versi baru sendiri; jika tidak ingin menunggu, gunakan Pengaturan → Periksa pembaruan sekarang.

Windows menyatakan telah “melindungi PC Anda”

Info selengkapnya → Tetap jalankan. Rincian dan cara memeriksa berkas ada di panduan pemasangan.

Lampu tombol ETS2 tidak menyala

Apakah plugin sudah terpasang? Pengaturan → Game (ETS2 / ATS). Jika sudah, mulai ulang game dan klik OK pada pemberitahuan “fitur SDK lanjutan”.

OBS tidak terhubung

Apakah OBS terbuka, server WebSocket-nya aktif, serta port dan kata sandinya benar? Rinciannya ada di panduan OBS.

Discord tidak mendengar saya

Di Discord, pilih perangkat yang ditunjukkan wizard Siapkan untuk Discord sebagai perangkat input, lalu jalankan langkah Uji di wizard.

Masih bermasalah?

Di program, Laporkan masalah… membuat paket diagnostik (zip); kunci pemasangan dan kata sandi tidak disertakan. Kirimkan lewat email ke admin@paneldeck.info beserta penjelasan singkat masalahnya.
