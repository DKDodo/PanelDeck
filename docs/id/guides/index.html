Panduan

Panduan langkah demi langkah

Dari pemasangan hingga game dan streaming: panduan singkat untuk memaksimalkan PanelDeck.

📲

Pemasangan dan koneksi

Pasang program dan aplikasi, lalu hubungkan ponsel dengan kode QR.
🚚

ETS2 dan ATS

Pasang plugin: dasbor langsung, lampu indikator, dan getaran.
🎥

OBS Studio

Aktifkan WebSocket: adegan, rekam, siaran, dan peringatan kondisi stream.
🎧

Discord dan efek suara

Kirim suara yang diubah dan suara siap pakai ke Discord.
🖥️

Layar kedua dan koneksi jarak jauh

Tampilkan monitor di ponsel dan terhubung dari luar rumah lewat data seluler.
🛠️

Pemecahan masalah

Solusi cepat untuk koneksi, versi, ETS2, OBS, dan Discord.
