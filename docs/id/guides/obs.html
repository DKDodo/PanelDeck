🎥 OBS Studio

Aktifkan WebSocket: adegan, rekam, siaran, dan peringatan kondisi stream.

PanelDeck terhubung ke OBS Studio lewat WebSocket bawaan OBS: ganti adegan, rekam, siaran, simpan klip, dan kendalikan sumber audio dari ponsel.

1. Aktifkan WebSocket di OBS

  1. Di OBS: Alat → Pengaturan Server WebSocket → Aktifkan server WebSocket.
  2. Catat port (bawaannya 4455) dan kata sandinya.

2. Hubungkan PanelDeck

  1. Di program, buka Pengaturan → kartu OBS Studio dan centang Kontrol OBS dari ponsel (adegan, perekaman, streaming, audio).
  2. Masukkan server 127.0.0.1, port 4455, dan kata sandi OBS, lalu klik Simpan. Selama OBS tertutup, program mencoba lagi setiap beberapa detik.

3. Tambahkan tombol

Pilih sebuah tombol lalu pilih aksi adegan, rekam, siaran, klip, atau sumber audio dari bagian OBS di daftar Tindakan siap pakai. Pengatur waktu rekam dan siaran tampil langsung di tombol. Tata letak siap pakai Streamer sudah berisi sebagian besar tombol ini.

Peringatan kondisi siaran (Beta, Pro)

Saat terjadi kemacetan, bingkai hilang, atau bitrate turun, ponsel bergetar dan menampilkan strip berwarna di bagian atas layar. Fitur ini bekerja saat fitur eksperimental (Beta) aktif di Pengaturan program. Untuk mematikannya, hapus centang Peringatan getar di ponsel saat siaran bermasalah di kartu Pengaturan → OBS Studio.
