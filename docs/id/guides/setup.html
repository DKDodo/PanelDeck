📲 Pemasangan dan koneksi

Pasang program dan aplikasi, lalu hubungkan ponsel dengan kode QR.

PanelDeck terdiri dari dua bagian: program untuk Windows dan aplikasi untuk Android. Keduanya harus memakai versi yang sama; program menemukan versi baru sendiri.

1. Pasang program di PC

  1. Unduh dan jalankan penginstal PanelDeck. Tidak perlu hak administrator.
  2. Jika Windows menyatakan telah “melindungi PC Anda”, klik Info selengkapnya → Tetap jalankan. Rinciannya ada di panduan pemasangan.
  3. Saat pertama kali dibuka, program membuka wizard Sambungkan ponsel Anda.

2. Pasang aplikasi di ponsel

  1. Pindai kode unduhan di wizard dengan kamera ponsel.
  2. Ketuk berkas UsbDeck.apk yang telah diunduh.
  3. Jika Android meminta, aktifkan Izinkan dari sumber ini, lalu ketuk Instal. Mode pengembang tidak diperlukan.

3. Pasangkan keduanya (Wi‑Fi, disarankan)

  1. Pastikan PC dan ponsel berada di jaringan Wi‑Fi yang sama.
  2. Buka PanelDeck di ponsel, ketuk Sambungkan dengan kode QR lalu pindai kode di PC.
  3. Ketuk Pasangkan. Jika Windows Firewall bertanya, izinkan jaringan “Pribadi” dan “Publik”.

Untuk membuka wizard lagi nanti, gunakan tombol ＋ Tambah ponsel di bilah atas program.

Terhubung lewat USB (lanjutan)

Untuk terhubung dengan kabel, Debugging USB harus aktif di Opsi pengembang ponsel. Bagian USB di wizard menampilkan langkah-langkah dan status koneksi secara langsung.

Di luar rumah

Setelah dipasangkan, ponsel juga terhubung lewat data seluler saat tidak ada Wi‑Fi yang sama; tidak ada yang perlu diatur, dan koneksinya terenkripsi end-to-end. Rinciannya ada di panduan layar kedua dan koneksi jarak jauh.

Untuk tata letak pertama, pilih Streamer, Gamer, Kantor, atau Mengemudi truk di Profil → Tata letak siap pakai…; logo asli program Anda ditambahkan otomatis.
