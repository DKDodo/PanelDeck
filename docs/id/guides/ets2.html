🚚 ETS2 dan ATS

Pasang plugin: dasbor langsung, lampu indikator, dan getaran.

Untuk Euro Truck Simulator 2 dan American Truck Simulator, PanelDeck menambahkan lampu yang menunjukkan kondisi di dalam game ke tombol Anda, serta dasbor langsung di ponsel.

1. Pasang plugin

  1. Di program, buka Pengaturan → kartu Game (ETS2 / ATS) lalu klik Pasang plugin. Plugin telemetri kecil disalin ke folder game (sumber terbuka, MIT).
  2. Mulai ulang game. Setiap kali dibuka, game menampilkan pemberitahuan “fitur SDK lanjutan”: klik OK.

2. Tambahkan panel siap pakai

Di program: Profil → Tata letak siap pakai… → Mengemudi truk (ETS2 / ATS) → Gunakan. Dengan Pro lebih mudah lagi: saat game dimulai, ponsel menawarkan panel siap pakai; terima, dan ponsel akan beralih ke halaman itu setiap kali game dimulai.

3. Dasbor dan peringatan

  • Tombol Dasbor membuka dasbor layar penuh di ponsel: kecepatan, batas kecepatan, RPM, bahan bakar, waktu tiba, dan lampu indikator.
  • Tombol lampu, rem parkir, dan cruise control menyala sesuai kondisi di dalam game; melihat ke kiri atau kanan terkunci dengan sekali ketuk.
  • Peringatan getar (Beta, Pro): ponsel bergetar saat Anda melewati batas kecepatan, bahan bakar hampir habis, atau terjadi kerusakan baru. Fitur ini bekerja saat fitur eksperimental (Beta) aktif di Pengaturan program. Untuk mematikannya, di ponsel buka ⋯ → Pengaturan → Peringatan game dan stream.
Tombol mengirim tombol bawaan game. Jika Anda mengubah tombol di dalam game, pilih tombolnya di program lalu perbarui kolom Tombol di dalam game.
