Yang baru

Apa yang berubah di setiap versi. Program dan aplikasi menemukan versi baru sendiri.

Versi 0.16.3

  • ✉ Dukungan lewat email: admin@paneldeck.info. Paket “Laporkan masalah…” bisa dilampirkan ke email; tidak perlu akun GitHub
  • 📖 Tautan “Panduan” kini membuka panduan langkah demi langkah di situs dalam bahasa program (13 bahasa)
  • 🌐 Situs web punya alamat baru: www.paneldeck.info. Tautan di program mengarah ke sana

Versi 0.16.2

  • 🧪 Fitur yang belum diuji dalam penggunaan nyata kini berstatus “Beta”: Twitch, impor Stream Deck, panduan penyiapan Discord, dan peringatan getar muncul saat Pengaturan → Fitur eksperimental (Beta) aktif. Tombol yang sudah ada tetap berfungsi
  • 🔒 Galeri profil dan Elgato Key Light “segera hadir” sampai selesai diuji
  • 🛠 Plugin: spasi sebelum dan sesudah nilai langsung kini dipertahankan (misalnya “4.3 km/h”)

Versi 0.16.1

  • ⚡ Koneksi lebih andal: tombol permintaan web, Twitch, plugin, dan pemeriksaan pembaruan tidak lagi membanjiri server dengan permintaan berulang; info yang sama disimpan sebentar di cache dan tata letak yang tidak berubah tidak diunggah ulang ke cloud
  • 🛠 Perbaikan: satu tombol bermasalah tidak lagi menghentikan seluruh impor Stream Deck; masuk Twitch dan plugin lebih tahan terhadap galat jaringan; menekan tombol klip / iklan Twitch dua kali tidak lagi menjalankannya dua kali
  • 📄 Kebijakan privasi dan ketentuan penggunaan diperbarui untuk fitur baru (Twitch, plugin, mikrofon rapat): jendela Tentang

Versi 0.16.0

  • 🎨 Panel program: halaman pintasan siap pakai untuk Photoshop, Premiere Pro, After Effects, Illustrator, DaVinci Resolve, Blender, Figma, dan VS Code (Profil → Tata letak siap pakai…). Saat program tampil di depan, ponsel menawarkan untuk menyiapkannya (Pro)
  • 🎙 Mikrofon rapat: tombol yang membisukan dan menyalakan mikrofon di Teams, Zoom, Meet, Webex, dan Slack tanpa pintasan, bahkan saat jendela di latar belakang; lampu di ponsel menunjukkan statusnya
  • 🌍 8 bahasa baru: Rusia, Italia, Prancis, Belanda, Indonesia, Tionghoa, Jepang, dan Korea (komputer dan ponsel)
  • 🎛 Studio suara (Pro): 11 suara baru, termasuk suara alami perempuan, laki-laki, anak, dan lansia; buat dan simpan suara Anda sendiri dengan penggeser; noise gate dan kompresor. Efek suara → “Studio suara…”
  • 📥 Impor profil Stream Deck Anda: Profil → “Impor profil Stream Deck…” (pintasan, situs web, teks, multi-aksi, folder, dan tombol OBS)
  • 📺 Twitch (Pro): tombol untuk klip, penanda siaran, iklan, pesan obrolan, dan mode obrolan; jumlah penonton, durasi siaran, dan pengikut secara langsung. Pengaturan → Siaran langsung: Twitch
  • 🧩 Plugin: tambahkan tombol siap pakai dan info langsung baru dengan plugin satu berkas. Pengaturan → Plugin

Versi 0.15.3

  • 📚 Panduan: panduan langkah demi langkah untuk penyiapan, ETS2 / ATS, OBS, Discord, dan pemecahan masalah di situs web, dalam 5 bahasa. Buka dari jendela Tentang atau Pengaturan → Umum

Versi 0.15.2

  • 📖 Jendela “Tentang” baru: ketentuan penggunaan, kebijakan privasi, dan lisensi sumber terbuka kini ada di dalam program, tanpa perlu internet (klik teks versi di kiri bawah)

Versi 0.15.1

  • 📄 Ketentuan penggunaan, kebijakan privasi, dan lisensi sumber terbuka: di bagian bawah Pengaturan → Umum

Versi 0.15.0

  • 🖼 Logo asli: tombol seperti Discord, Steam, YouTube, dan WhatsApp menampilkan logo program atau situs itu sendiri (diterapkan sekali ke tombol yang ada)
  • 📳 Peringatan getar (Pro): batas kecepatan, bahan bakar, dan kerusakan di ETS2/ATS; kepadatan, frame hilang, dan penurunan bitrate di stream OBS
  • 🎮 Tanpa penyiapan: saat game dimulai, ponsel menawarkan untuk menyiapkan panel siap pakainya lalu beralih ke sana dengan sendirinya
  • 🧪 Dukungan balap dan penerbangan kini berada di balik sakelar “Fitur eksperimental (Beta)” (Pengaturan)

Versi 0.14.1

  • 🎨 Bilah judul jendela kini serasi dengan antarmuka biru tua: tidak ada lagi strip putih
  • 🛠 Cadangan cloud: cadangan lama hanya ditawarkan di komputer yang baru dipasang

Versi 0.14.0

  • ☁ Cadangan cloud (Pro): tata letak Anda disimpan terenkripsi; jika Windows dipasang ulang atau Anda berganti komputer, tata letak kembali dengan ponsel Anda. Pengaturan → Cadangan cloud

Versi 0.13.3

  • ✨ Tampilan baru: tema Malam dan emas. Untuk menyesuaikan tombol juga: Profil → “Sesuaikan warna dengan tema Malam”
  • 📡 Layar kedua kini juga terbuka lewat data seluler (koneksi jarak jauh): kualitas rendah, beberapa frame per detik, 20 menit per sesi
  • 🛠 Penyiapan otomatis layar samping ETS2 / ATS dihapus: game tidak membentang di monitor terpisah, gambar terjepit di layar utama. Jika Anda sempat memakainya: Pengaturan → Game → “Urungkan penyiapan layar samping…”

Versi 0.13.2

  • 👈 Lihat kiri / kanan kini terkunci dengan satu ketukan; “🎯 Lihat depan” kembali ke tampilan utama
  • 📱 Kartu baru “Jadikan ponsel monitor tambahan” di halaman Layar kedua: layar samping ETS2 / ATS dengan satu klik

Versi 0.13.1

  • 📱 Gunakan ponsel sebagai layar samping di game (ETS2 / ATS, eksperimental): Pengaturan → Game → “Gunakan ponsel sebagai layar samping di game…”
  • 🖥 Layar kedua: menu opsi baru, monitor berdasarkan nama model; monitor virtual ditampilkan sebagai “layar ponsel / tablet”
  • 🚦 Ikon lampu indikator dasbor asli pada tombol truk dan dasbor; layar Pro baru; saran kisi yang lebih lebar di tablet

Versi 0.13.0

  • 🌍 Koneksi jarak jauh: ponsel juga tersambung lewat data seluler atau Wi‑Fi lain; tidak perlu Tailscale, penyiapan router, atau pemasangan (terenkripsi ujung ke ujung)
  • ⏱ Tombol timer: ketuk untuk memulai hitung mundur, sisa waktu ditampilkan di tombol; saat waktu habis ponsel bergetar dan berbunyi, dan PC memutar peringatan (siap pakai: Fokus 25 mnt, Istirahat 5 mnt)
  • 💾 Cadangan otomatis: tata letak Anda dicadangkan setiap hari dan sebelum banyak hal dihapus; kembali dengan satu klik di Profil → Cadangan otomatis…
  • ✈ X-Plane 11 / 12: tombol untuk lampu, roda pendarat, flap, rem parkir, dan autopilot (lampunya menampilkan status di X-Plane) serta pengukur untuk kecepatan, ketinggian, kecepatan vertikal, arah, dan bahan bakar; tata letak siap pakai: Penerbangan
  • 💻 Beberapa komputer: ponsel mengingat setiap PC yang dipasangkan; beralih dengan ⋯ → Komputer di ponsel
  • 🏎 Dasbor balap: gigi, lampu perpindahan gigi, waktu putaran, posisi, dan bahan bakar layar penuh di ponsel untuk Forza Horizon / Motorsport, F1 23-25, BeamNG, dan Assetto Corsa; tata letak siap pakai: Game balap
  • 📦 Galeri profil: impor profil siap pakai yang dibagikan orang lain dengan satu klik di Profil → Galeri profil…
  • ✨ Jendela “Yang baru” ini: menampilkan apa yang berubah setelah pembaruan

Versi lama dan semua berkas: halaman rilis di GitHub.
