🚚 ETS2와 ATS

플러그인 설치: 실시간 대시보드, 경고등, 진동.

Euro Truck Simulator 2와 American Truck Simulator에서 PanelDeck은 버튼에 게임 상태를 보여 주는 표시등을 더하고, 휴대폰에 실시간 대시보드를 띄웁니다.

1. 플러그인 설치

  1. 프로그램에서 설정 → 게임(ETS2 / ATS) 카드를 열고 플러그인 설치를 클릭하세요. 작은 텔레메트리 플러그인이 게임 폴더에 복사됩니다(오픈 소스, MIT).
  2. 게임을 다시 시작하세요. 실행할 때마다 '고급 SDK 기능' 알림이 나오면 OK를 클릭하세요.

2. 준비된 패널 추가

프로그램에서: 프로필 → 기본 제공 레이아웃… → 트럭 운전(ETS2 / ATS) → 사용. Pro라면 더 쉽습니다. 게임을 시작하면 휴대폰이 준비된 패널을 제안하고, 수락하면 이후 게임을 시작할 때마다 그 페이지로 전환합니다.

3. 대시보드와 알림

  • 대시보드 버튼은 휴대폰에 전체 화면 대시보드를 엽니다: 속도, 제한 속도, RPM, 연료, 도착 시간, 경고등.
  • 전조등, 주차 브레이크, 크루즈 컨트롤 버튼은 게임 상태에 맞춰 켜집니다. 왼쪽이나 오른쪽 보기는 한 번 탭하면 고정됩니다.
  • 진동 알림(베타, Pro): 제한 속도를 넘거나 연료가 부족하거나 새로운 손상이 생기면 휴대폰이 진동합니다. 프로그램 설정에서 실험적 기능(베타)이 켜져 있을 때 작동합니다. 끄려면 휴대폰에서 ⋯ → 설정 → 게임 및 방송 알림을 여세요.
버튼은 게임의 기본 키를 보냅니다. 게임에서 키를 바꿨다면 프로그램에서 버튼을 선택하고 게임 내 키 항목을 수정하세요.
