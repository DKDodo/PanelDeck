📲 설치와 연결

프로그램과 앱을 설치한 뒤 QR 코드로 휴대폰을 연결하세요.

PanelDeck은 Windows 프로그램과 Android 앱 두 부분으로 이루어져 있습니다. 둘 다 같은 버전이어야 하며, 프로그램이 새 버전을 자동으로 찾습니다.

1. PC에 프로그램 설치

  1. PanelDeck 설치 프로그램을 다운로드해 실행하세요. 관리자 권한은 필요 없습니다.
  2. Windows가 'PC를 보호했습니다'라고 표시하면 추가 정보 → 실행을 클릭하세요. 자세한 내용은 설치 가이드에 있습니다.
  3. 처음 실행하면 프로그램이 휴대폰 연결 마법사를 엽니다.

2. 휴대폰에 앱 설치

  1. 마법사의 다운로드 코드를 휴대폰 카메라로 스캔하세요.
  2. 다운로드한 UsbDeck.apk 파일을 탭하세요.
  3. Android가 물으면 이 출처 허용을 켠 뒤 설치를 탭하세요. 개발자 모드는 필요 없습니다.

3. 페어링(Wi‑Fi, 권장)

  1. PC와 휴대폰이 같은 Wi‑Fi 네트워크에 있는지 확인하세요.
  2. 휴대폰에서 PanelDeck을 열고 QR 코드로 연결을 탭한 다음 PC의 코드를 스캔하세요.
  3. 페어링을 탭하세요. Windows 방화벽이 물으면 '개인'과 '공용' 네트워크를 모두 허용하세요.

나중에 마법사를 다시 열려면 프로그램 상단 바의 ＋ 휴대폰 추가 버튼을 사용하세요.

USB로 연결(고급)

케이블로 연결하려면 휴대폰의 개발자 옵션에서 USB 디버깅이 켜져 있어야 합니다. 마법사의 USB 섹션에 단계와 실시간 연결 상태가 표시됩니다.

집 밖에서

페어링이 끝나면 같은 Wi‑Fi가 없을 때도 휴대폰이 모바일 데이터로 연결됩니다. 설정할 것이 없으며 연결은 종단 간 암호화됩니다. 자세한 내용은 보조 화면과 원격 연결 가이드에 있습니다.

첫 레이아웃으로 프로필 → 기본 제공 레이아웃…에서 '스트리머', '게이머', '사무', '트럭 운전' 중 하나를 고르세요. 프로그램의 실제 로고가 자동으로 추가됩니다.
