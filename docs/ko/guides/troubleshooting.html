🛠️ 문제 해결

연결, 버전, ETS2, OBS, Discord 문제를 빠르게 해결하세요.

휴대폰이 연결되지 않아요

  • PC와 휴대폰이 같은 Wi‑Fi에 있나요? 아니라면 휴대폰은 모바일 데이터로 원격 연결하며, 몇 초 걸릴 수 있습니다.
  • 프로그램에서 같은 네트워크의 무선 액세스(Wi‑Fi)가 켜져 있어야 합니다(설정 → 무선 연결 카드).
  • Windows 방화벽이 물었다면 '개인'과 '공용' 네트워크를 모두 허용하세요.
  • QR 코드를 다시 스캔하세요: 휴대폰에서 ⋯ → QR 코드 스캔.
  • 휴대폰을 잃어버렸나요? 프로그램에서 설정 → 페어링 키 갱신. 이전 페어링은 더 이상 작동하지 않습니다.

'버전 불일치' 경고

PC 프로그램과 휴대폰 앱을 같은 버전으로 업데이트하세요. 프로그램이 새 버전을 자동으로 찾습니다. 기다리기 싫다면 설정 → 지금 업데이트 확인을 사용하세요.

Windows가 'PC를 보호했습니다'라고 표시해요

추가 정보 → 실행. 자세한 내용과 파일 확인 방법은 설치 가이드에 있습니다.

ETS2 버튼 표시등이 켜지지 않아요

플러그인이 설치되어 있나요? 설정 → 게임(ETS2 / ATS). 설치되어 있다면 게임을 다시 시작하고 '고급 SDK 기능' 알림에서 OK를 클릭하세요.

OBS가 연결되지 않아요

OBS가 열려 있고, WebSocket 서버가 켜져 있으며, 포트와 비밀번호가 맞나요? 자세한 내용은 OBS 가이드에 있습니다.

Discord에서 제 목소리가 안 들려요

Discord에서 Discord용으로 설정 마법사가 보여 주는 장치를 입력 장치로 선택하고, 마법사의 테스트 단계를 실행하세요.

그래도 해결되지 않나요?

프로그램의 문제 신고…는 진단 패키지(zip)를 만듭니다. 페어링 키와 비밀번호는 포함되지 않습니다. 문제를 간단히 설명해 admin@paneldeck.info(으)로 이메일을 보내 주세요.
