🖥️ 보조 화면과 원격 연결

모니터를 휴대폰에 띄우고 밖에서는 모바일 데이터로 연결하세요.

보조 화면(Pro)

  1. 프로그램에서 설정 → 보조 화면 카드를 열고 보조 화면: 모니터를 휴대폰으로 스트리밍에 체크하세요.
  2. 터치로 사용하려면 휴대폰을 마우스(터치)와 키보드로 사용도 켜세요.
  3. 휴대폰에서 ⋯ → 보조 화면을 여세요.

모니터가 여러 대라면 휴대폰에 어떤 모니터를 띄울지 고를 수 있습니다. 화면은 페어링한 휴대폰으로만 전송되며 절대 녹화되지 않습니다.

원격 연결(모바일 데이터)

  • 같은 Wi‑Fi가 없으면 휴대폰은 PanelDeck 릴레이를 통해 연결됩니다. 설정할 것이 없으며, 연결은 종단 간 암호화되어 릴레이는 내용을 볼 수 없습니다.
  • 모바일 데이터에서는 보조 화면이 낮은 화질(초당 최대 4프레임)로 실행되고 한 세션은 최대 20분입니다. 다시 열 수 있습니다. 앱이 매번 데이터 사용량을 경고합니다.
  • 끄려면 프로그램의 설정 → 무선 연결 카드에서 원격 연결: 모바일 데이터로도 연결 체크를 해제하세요.
모바일 데이터 요금은 사용자와 통신사 사이의 문제입니다. 보조 화면을 오래 쓸 때는 Wi‑Fi를 권장합니다.
