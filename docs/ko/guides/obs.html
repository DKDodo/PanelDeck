🎥 OBS Studio

WebSocket을 켜세요: 장면, 녹화, 방송, 방송 상태 알림.

PanelDeck은 OBS 자체 WebSocket을 통해 OBS Studio에 연결됩니다. 휴대폰에서 장면 전환, 녹화, 방송, 클립 저장, 오디오 소스 제어를 할 수 있습니다.

1. OBS에서 WebSocket 켜기

  1. OBS에서: 도구 → WebSocket 서버 설정 → WebSocket 서버 활성화.
  2. 포트(기본값 4455)와 비밀번호를 적어 두세요.

2. PanelDeck 연결

  1. 프로그램에서 설정 → OBS Studio 카드를 열고 휴대폰에서 OBS 제어(장면, 녹화, 스트리밍, 오디오)에 체크하세요.
  2. 서버 127.0.0.1, 포트 4455, OBS 비밀번호를 입력하고 저장을 클릭하세요. OBS가 닫혀 있는 동안 프로그램은 몇 초마다 다시 시도합니다.

3. 버튼 추가

버튼을 선택하고 기본 제공 동작 목록의 OBS 섹션에서 장면, 녹화, 방송, 클립, 오디오 소스 동작을 고르세요. 녹화와 방송 타이머는 버튼 위에 바로 표시됩니다. 기본 제공 스트리머 레이아웃에는 이 버튼 대부분이 이미 들어 있습니다.

방송 상태 알림(베타, Pro)

혼잡, 프레임 손실, 비트레이트 하락이 생기면 휴대폰이 진동하고 화면 위쪽에 색 띠가 나타납니다. 프로그램 설정에서 실험적 기능(베타)이 켜져 있을 때 작동합니다. 끄려면 설정 → OBS Studio 카드에서 방송 문제 시 휴대폰 진동 알림 체크를 해제하세요.
