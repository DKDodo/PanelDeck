🎧 Discord와 효과음

변조한 목소리와 준비된 사운드를 Discord로 보내세요.

음성 변조기와 기본 제공 사운드는 나만 듣게 하거나 Discord의 친구들에게도 들려줄 수 있습니다. Discord로 소리를 보내기 위해 마이크가 무료 가상 오디오 케이블인 Voicemeeter를 거쳐 Discord로 전달됩니다.

1. 설정 마법사

  1. 프로그램에서 음향 효과 페이지를 열고 🎧 Discord용으로 설정을 클릭하세요.
  2. 마법사가 단계를 순서대로 보여 줍니다. 대부분 클릭 한 번이면 됩니다. Voicemeeter가 설치되어 있지 않으면 다운로드 페이지를 엽니다.
  3. Discord에서 설정 → 음성 및 비디오를 열고 마법사가 보여 주는 장치를 입력 장치로 선택하세요. 해당 단계가 자동으로 ✓로 바뀝니다.
  4. 마법사의 테스트로 짧은 신호음을 사용해 전체 경로를 확인하세요. 실행 취소는 마법사가 바꾼 Voicemeeter 설정을 되돌립니다.

2. 누가 들어야 하나요?

나만, Discord의 모든 사람 또는 나와 Discord. 음성 변조기와 기본 제공 사운드를 따로 선택합니다.

3. 효과와 사운드

  • 음성 변조기: 굵은 목소리, 높은 목소리, 괴물, 외계인, 로봇, 에코, 동굴, 무전기.
  • 기본 제공 사운드: ＋ 사운드 추가…로 내 .wav 파일을 추가하거나 ✨ 기본 제공 사운드 추가를 사용하세요. 패널에 버튼으로 추가로 휴대폰에 올릴 수 있습니다.
Discord 마이크나 헤드셋을 음소거하려고 단축키를 지정할 필요가 없습니다. Discord가 음성 채널에 있는 동안 기본 제공 Discord 마이크와 Discord 헤드셋 음소거 버튼이 바로 작동합니다.
