새로운 기능

버전별 변경 사항. 프로그램과 앱이 새 버전을 자동으로 찾습니다.

버전 0.16.2

  • 🧪 아직 실제 사용에서 테스트되지 않은 기능은 이제 ‘베타’입니다. Twitch, Stream Deck 가져오기, Discord 설정 마법사, 진동 알림은 설정 → 실험적 기능(베타)이 켜져 있을 때 표시됩니다. 기존 버튼은 계속 작동합니다
  • 🔒 프로필 갤러리와 Elgato Key Light는 테스트가 끝날 때까지 ‘곧 제공’됩니다
  • 🛠 플러그인: 실시간 값 앞뒤의 공백이 이제 유지됩니다(예: ‘4.3 km/h’)

버전 0.16.1

  • ⚡ 더 안정적인 연결: 웹 요청 버튼, Twitch, 플러그인, 업데이트 확인이 서버에 반복 요청을 보내지 않습니다. 같은 정보는 잠시 캐시되고 바뀌지 않은 레이아웃은 클라우드에 다시 올리지 않습니다
  • 🛠 수정: 문제 있는 버튼 하나 때문에 Stream Deck 가져오기 전체가 멈추지 않습니다. Twitch 로그인과 플러그인이 네트워크 오류에 더 강해졌습니다. Twitch 클립 / 광고 버튼을 두 번 눌러도 두 번 실행되지 않습니다
  • 📄 개인정보 처리방침과 이용 약관을 새 기능(Twitch, 플러그인, 회의 마이크)에 맞게 업데이트했습니다: 정보 창

버전 0.16.0

  • 🎨 프로그램 패널: Photoshop, Premiere Pro, After Effects, Illustrator, DaVinci Resolve, Blender, Figma, VS Code용 단축키 페이지(프로필 → 기본 제공 레이아웃…). 프로그램이 앞에 오면 휴대폰이 설정을 제안합니다(Pro)
  • 🎙 회의 마이크: Teams, Zoom, Meet, Webex, Slack에서 단축키 없이 마이크를 끄고 켜는 버튼. 창이 뒤에 있어도 작동하며 휴대폰의 표시등으로 상태를 확인할 수 있습니다
  • 🌍 8개 새 언어: 러시아어, 이탈리아어, 프랑스어, 네덜란드어, 인도네시아어, 중국어, 일본어, 한국어(컴퓨터와 휴대폰)
  • 🎛 보이스 스튜디오(Pro): 자연스러운 여성, 남성, 어린이, 노인 목소리를 포함한 11가지 새 목소리, 슬라이더로 나만의 목소리를 만들어 저장, 노이즈 게이트와 컴프레서. 음향 효과 → ‘보이스 스튜디오…’
  • 📥 Stream Deck 프로필 가져오기: 프로필 → ‘Stream Deck 프로필 가져오기…’(단축키, 웹사이트, 텍스트, 멀티 액션, 폴더, OBS 버튼)
  • 📺 Twitch(Pro): 클립, 방송 마커, 광고, 채팅 메시지, 채팅 모드 버튼, 시청자 수, 방송 시간, 팔로워 실시간 표시. 설정 → 라이브 방송: Twitch
  • 🧩 플러그인: 파일 하나짜리 플러그인으로 새 기본 버튼과 실시간 정보를 추가하세요. 설정 → 플러그인

버전 0.15.3

  • 📚 가이드: 설정, ETS2 / ATS, OBS, Discord, 문제 해결에 대한 단계별 가이드를 웹사이트에서 5개 언어로 제공합니다. '정보' 창이나 설정 → 일반에서 열 수 있습니다

버전 0.15.2

  • 📖 새 '정보' 창: 이용 약관, 개인정보 처리방침, 오픈 소스 라이선스를 이제 인터넷 없이 프로그램 안에서 볼 수 있습니다(왼쪽 아래의 버전 텍스트 클릭)

버전 0.15.1

  • 📄 이용 약관, 개인정보 처리방침, 오픈 소스 라이선스: 설정 → 일반 맨 아래

버전 0.15.0

  • 🖼 실제 로고: Discord, Steam, YouTube, WhatsApp 같은 버튼에 프로그램이나 사이트 자체 로고가 표시됩니다(기존 버튼에 한 번 적용)
  • 📳 진동 알림(Pro): ETS2/ATS의 제한 속도, 연료, 손상; OBS 방송의 혼잡, 드롭된 프레임, 비트레이트 하락
  • 🎮 설정 필요 없음: 게임이 시작되면 휴대폰이 기본 제공 패널 설정을 제안하고 이후에는 자동으로 전환합니다
  • 🧪 레이싱과 비행 지원이 이제 '실험적 기능(베타)' 스위치(설정) 뒤에 있습니다

버전 0.14.1

  • 🎨 창 제목 표시줄이 이제 남색 인터페이스와 어울립니다: 흰 띠가 없어졌습니다
  • 🛠 클라우드 백업: 이전 백업은 새로 설치한 컴퓨터에서만 제안됩니다

버전 0.14.0

  • ☁ 클라우드 백업(Pro): 레이아웃이 암호화되어 저장됩니다. Windows를 다시 설치하거나 컴퓨터를 바꿔도 휴대폰으로 되찾을 수 있습니다. 설정 → 클라우드 백업

버전 0.13.3

  • ✨ 새 디자인: 야간 & 골드 테마. 버튼도 맞추려면: 프로필 → '색상을 야간 테마에 맞추기'
  • 📡 이제 보조 화면이 모바일 데이터(원격 연결)로도 열립니다: 저화질, 초당 몇 프레임, 세션당 20분
  • 🛠 ETS2 / ATS 측면 화면 자동 설정을 제거했습니다: 게임이 별도 모니터에 걸쳐 표시되지 않고 화면이 메인 화면에 눌려 보였습니다. 사용했다면: 설정 → 게임 → '측면 화면 설정 되돌리기…'

버전 0.13.2

  • 👈 왼쪽 / 오른쪽 보기가 이제 한 번 탭하면 고정됩니다. '🎯 앞 보기'로 기본 시점으로 돌아갑니다
  • 📱 보조 화면 페이지에 새 카드 '휴대폰을 추가 모니터로 만들기': 클릭 한 번으로 ETS2 / ATS 측면 화면

버전 0.13.1

  • 📱 게임에서 휴대폰을 측면 화면으로 사용(ETS2 / ATS, 실험적): 설정 → 게임 → '게임에서 휴대폰을 측면 화면으로 사용…'
  • 🖥 보조 화면: 새 옵션 메뉴, 모델 이름으로 모니터 표시. 가상 모니터는 '휴대폰 / 태블릿 화면'으로 표시됩니다
  • 🚦 트럭 버튼과 대시보드에 실제 계기판 경고등 아이콘, 새 Pro 화면, 태블릿에서 더 넓은 격자 제안

버전 0.13.0

  • 🌍 원격 연결: 휴대폰이 모바일 데이터나 다른 Wi‑Fi로도 연결됩니다. Tailscale, 라우터 설정, 설치가 필요 없습니다(종단 간 암호화)
  • ⏱ 타이머 버튼: 탭하면 카운트다운이 시작되고 남은 시간이 버튼에 표시됩니다. 시간이 다 되면 휴대폰이 진동하고 소리가 나며 PC에서 알림이 재생됩니다(기본 제공: 집중 25분, 휴식 5분)
  • 💾 자동 백업: 레이아웃이 매일, 그리고 많이 삭제하기 전에 백업됩니다. 프로필 → 자동 백업…에서 클릭 한 번으로 되돌리세요
  • ✈ X-Plane 11 / 12: 조명, 랜딩 기어, 플랩, 주차 브레이크, 자동 조종 버튼(표시등이 X-Plane의 상태를 보여 줌)과 속도, 고도, 수직 속도, 기수 방향, 연료 계기. 기본 제공 레이아웃: 비행
  • 💻 여러 컴퓨터: 휴대폰이 페어링한 모든 PC를 기억합니다. 휴대폰에서 ⋯ → 컴퓨터로 전환하세요
  • 🏎 레이싱 대시보드: Forza Horizon / Motorsport, F1 23-25, BeamNG, Assetto Corsa의 기어, 변속 표시등, 랩 타임, 순위, 연료를 휴대폰 전체 화면으로 표시. 기본 제공 레이아웃: 레이싱 게임
  • 📦 프로필 갤러리: 다른 사람이 공유한 기본 제공 프로필을 프로필 → 프로필 갤러리…에서 클릭 한 번으로 가져오세요
  • ✨ 이 '새로운 기능' 창: 업데이트 후 무엇이 바뀌었는지 보여 줍니다
