What's new

What changed in each version. The program and the phone app find new versions by themselves.

Version 0.15.2

  • 📖 New “About” window: the terms of use, privacy policy and open-source licenses are now inside the program, no internet needed (click the version text at the bottom left)

Version 0.15.1

  • 📄 Terms of use, privacy policy and open-source licenses: at the bottom of Settings → General

Version 0.15.0

  • 🖼 Real logos: buttons like Discord, Steam, YouTube and WhatsApp show the program's or site's own logo (applied once to existing buttons)
  • 📳 Vibration alerts (Pro): speed limit, fuel and damage in ETS2/ATS; congestion, dropped frames and bitrate drops in OBS streams
  • 🎮 Zero setup: when a game starts, the phone offers to set up its ready-made panel and then switches to it by itself
  • 🧪 Racing and flight support now sits behind the “Experimental features (Beta)” switch (Settings)

Version 0.14.1

  • 🎨 The window title bar now matches the navy interface: no more white strip
  • 🛠 Cloud backup: old backups are only offered on a freshly installed computer

Version 0.14.0

  • ☁ Cloud backup (Pro): your layout is stored encrypted; if Windows is reinstalled or you change computers, it comes back with your phone. Settings → Cloud backup

Version 0.13.3

  • ✨ New look: the Night and gold theme. To match the buttons too: Profile → “Match colors to the Night theme”
  • 📡 The second screen now also opens over mobile data (remote connection): low quality, a few frames per second, 20 minutes per session
  • 🛠 The automatic ETS2 / ATS side screen setup was removed: the game does not span separate monitors, the picture was squeezed onto the main screen. If you used it: Settings → Games → “Undo the side screen setup…”

Version 0.13.2

  • 👈 Look left / right now lock with one tap; “🎯 Look ahead” returns to the main view
  • 📱 New “Make the phone an extra monitor” card on the Second screen page: ETS2 / ATS side screen in one click

Version 0.13.1

  • 📱 Use the phone as a side screen in the game (ETS2 / ATS, experimental): Settings → Games → “Use the phone as a side screen in the game…”
  • 🖥 Second screen: new options menu, monitors by model name; a virtual monitor shows as “phone / tablet screen”
  • 🚦 Real dashboard telltale icons on truck buttons and the dashboard; a new Pro screen; a wider grid suggestion on tablets

Version 0.13.0

  • 🌍 Remote connection: the phone also connects over mobile data or another Wi‑Fi; no Tailscale, router setup or install needed (end-to-end encrypted)
  • ⏱ Timer button: tap to start a countdown, the time left shows on the button; when time is up the phone vibrates and beeps and the PC plays an alert (ready-made: Focus 25 min, Break 5 min)
  • 💾 Automatic backup: your layout is backed up every day and before much is deleted; go back in one click with Profile → Automatic backups…
  • ✈ X-Plane 11 / 12: buttons for lights, landing gear, flaps, parking brake and autopilot (their lights show the state in X-Plane) and gauges for speed, altitude, vertical speed, heading and fuel; ready layout: Flight
  • 💻 Several computers: the phone remembers every PC it pairs with; switch with ⋯ → Computers on the phone
  • 🏎 Racing dashboard: full-screen gear, shift lights, lap times, position and fuel on the phone for Forza Horizon / Motorsport, F1 23-25, BeamNG and Assetto Corsa; ready layout: Racing games
  • 📦 Profile gallery: import ready-made profiles shared by others in one click with Profile → Profile gallery…
  • ✨ This “What's new” window: shows what changed after an update

Older versions and all download files: release page on GitHub.
