📲 Installation et connexion

Installez le logiciel et l'application, puis connectez le téléphone avec le code QR.

PanelDeck se compose de deux parties : le logiciel pour Windows et l'application Android. Les deux doivent avoir la même version ; le logiciel trouve seul les nouvelles versions.

1. Installez le logiciel sur le PC

  1. Téléchargez et lancez le programme d'installation de PanelDeck. Aucun droit d'administrateur n'est nécessaire.
  2. Si Windows indique qu'il « a protégé votre ordinateur », cliquez sur Informations complémentaires → Exécuter quand même. Détails dans le guide d'installation.
  3. Au premier démarrage, le logiciel ouvre l'assistant Connectez votre téléphone.

2. Installez l'application sur le téléphone

  1. Scannez le code de téléchargement de l'assistant avec l'appareil photo du téléphone.
  2. Touchez le fichier téléchargé UsbDeck.apk.
  3. Si Android le demande, activez Autoriser cette source, puis touchez Installer. Le mode développeur n'est pas nécessaire.

3. Associez-les (Wi‑Fi, recommandé)

  1. Vérifiez que le PC et le téléphone sont sur le même réseau Wi‑Fi.
  2. Ouvrez PanelDeck sur le téléphone, touchez Se connecter avec un code QR et scannez le code affiché sur le PC.
  3. Touchez Associer. Si le pare-feu Windows le demande, autorisez à la fois les réseaux « Privé » et « Public ».

Pour rouvrir l'assistant plus tard, utilisez le bouton ＋ Ajouter un téléphone dans la barre supérieure du logiciel.

Connexion par USB (avancé)

Pour vous connecter avec un câble, le Débogage USB doit être activé dans les options pour les développeurs du téléphone. La section USB de l'assistant affiche les étapes et l'état de la connexion en direct.

Hors de chez vous

Une fois associé, le téléphone se connecte aussi via les données mobiles quand il n'y a pas de Wi‑Fi commun ; rien à configurer, et la connexion est chiffrée de bout en bout. Détails dans le guide second écran et connexion à distance.

Pour une première disposition, choisissez Streamer, Joueur, Bureau ou Conduite de camion dans Profil → Dispositions prêtes… ; les vrais logos de vos logiciels sont ajoutés automatiquement.
