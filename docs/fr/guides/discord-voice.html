🎧 Discord et effets sonores

Envoyez votre voix modifiée et des sons prêts dans Discord.

Le modificateur de voix et les sons prêts peuvent être joués pour vous seul ou aussi pour vos amis sur Discord. Pour envoyer le son vers Discord, votre micro est acheminé vers Discord via Voicemeeter, un câble audio virtuel gratuit.

1. Assistant de configuration (Bêta)

  1. L'assistant est en bêta : activez d'abord Fonctions expérimentales (Bêta) dans les Paramètres du logiciel, puis ouvrez la page Effets sonores et cliquez sur 🎧 Configurer pour Discord (Bêta).
  2. L'assistant affiche les étapes dans l'ordre ; la plupart se font en un clic. Si Voicemeeter n'est pas installé, il ouvre la page de téléchargement.
  3. Dans Discord, ouvrez Paramètres → Voix et vidéo et choisissez comme Périphérique d'entrée celui indiqué par l'assistant ; l'étape passe à ✓ toute seule.
  4. Utilisez Tester dans l'assistant pour vérifier la chaîne avec un court signal. Annuler rétablit les réglages de Voicemeeter modifiés par l'assistant.

2. Qui doit l'entendre ?

Moi seulement, Tout le monde sur Discord ou Moi et Discord. Le choix est séparé pour le modificateur de voix et pour les sons prêts.

3. Effets et sons

  • Modificateur de voix : Voix grave, Voix aiguë, Monstre, Extraterrestre, Robot, Écho, Caverne, Radio.
  • Sons prêts à l’emploi : ajoutez vos propres fichiers .wav avec ＋ Ajouter un son… ou utilisez ✨ Ajouter des sons prêts à l’emploi ; placez-les sur le téléphone avec Ajouter au panneau comme bouton.
Inutile d'attribuer des raccourcis pour couper votre micro ou votre son Discord : les touches prêtes Micro Discord et Sourdine Discord fonctionnent directement tant que Discord est dans un salon vocal.
