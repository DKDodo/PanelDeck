🎥 OBS Studio

Activez WebSocket : scènes, enregistrement, diffusion et alertes sur l'état du stream.

PanelDeck se connecte à OBS Studio via le WebSocket intégré d'OBS : changez de scène, enregistrez, diffusez, sauvegardez des clips et contrôlez les sources audio depuis votre téléphone.

1. Activez le WebSocket dans OBS

  1. Dans OBS : Outils → Paramètres du serveur WebSocket → Activer le serveur WebSocket.
  2. Notez le port (4455 par défaut) et le mot de passe.

2. Connectez PanelDeck

  1. Dans le logiciel, ouvrez Paramètres → la carte OBS Studio et cochez Contrôler OBS depuis le téléphone (scènes, enregistrement, streaming, audio).
  2. Saisissez le serveur 127.0.0.1, le port 4455 et le mot de passe d'OBS, puis cliquez sur Enregistrer. Tant qu'OBS est fermé, le logiciel réessaie toutes les quelques secondes.

3. Ajoutez les touches

Sélectionnez une touche et choisissez une action de scène, d'enregistrement, de diffusion, de clip ou de source audio dans la section OBS de la liste Actions prêtes à l’emploi. Les minuteurs d'enregistrement et de diffusion s'affichent directement sur la touche. La disposition prête Streamer contient déjà la plupart de ces touches.

Alertes sur l'état du stream (Bêta, Pro)

En cas de congestion, d'images perdues ou de baisse du débit, le téléphone vibre et affiche une bande colorée en haut de l'écran. Cela fonctionne quand les fonctions expérimentales (Bêta) sont activées dans les Paramètres du logiciel. Pour le désactiver, décochez Alerte par vibration sur le téléphone en cas de problème de diffusion dans la carte Paramètres → OBS Studio.
