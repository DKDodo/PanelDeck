🚚 ETS2 et ATS

Installez le plugin : tableau de bord en direct, voyants et vibrations.

Pour Euro Truck Simulator 2 et American Truck Simulator, PanelDeck ajoute à vos touches des voyants qui reflètent l'état du jeu, ainsi qu'un tableau de bord en direct sur votre téléphone.

1. Installez le plugin

  1. Dans le logiciel, ouvrez Paramètres → la carte Jeux (ETS2 / ATS) et cliquez sur Installer le plugin. Un petit plugin de télémétrie est copié dans le dossier du jeu (open source, MIT).
  2. Redémarrez le jeu. Il affiche à chaque démarrage un avis sur les « fonctions SDK avancées » : cliquez sur OK.

2. Ajoutez le panneau prêt

Dans le logiciel : Profil → Dispositions prêtes… → Conduite de camion (ETS2 / ATS) → Utiliser. Avec Pro, c'est encore plus simple : au lancement du jeu, le téléphone propose le panneau prêt ; acceptez-le et le téléphone basculera sur cette page à chaque lancement du jeu.

3. Tableau de bord et alertes

  • La touche Tableau de bord ouvre un tableau de bord plein écran sur le téléphone : vitesse, limite de vitesse, régime, carburant, heure d'arrivée et voyants.
  • Les touches des phares, du frein de stationnement et du régulateur s'allument selon l'état du jeu ; le regard à gauche ou à droite se verrouille d'un geste.
  • Alertes par vibration (Bêta, Pro) : le téléphone vibre quand vous dépassez la limite de vitesse, quand le carburant est bas ou en cas de nouveaux dégâts. Elles fonctionnent quand les fonctions expérimentales (Bêta) sont activées dans les Paramètres du logiciel. Pour les désactiver, sur le téléphone ouvrez ⋯ → Paramètres → Alertes de jeu et de stream.
Les touches envoient les commandes par défaut du jeu. Si vous avez modifié une touche dans le jeu, sélectionnez le bouton dans le logiciel et mettez à jour son champ Touche en jeu.
