🛠️ Dépannage

Solutions rapides pour la connexion, les versions, ETS2, OBS et Discord.

Le téléphone ne se connecte pas

  • Le PC et le téléphone sont-ils sur le même Wi‑Fi ? Sinon, le téléphone se connecte à distance via les données mobiles, ce qui peut prendre quelques secondes.
  • Dans le logiciel, Accès sans fil (Wi‑Fi) sur le même réseau doit être activé (carte Paramètres → Connexion sans fil).
  • Si le pare-feu Windows l'a demandé, autorisez à la fois les réseaux « Privé » et « Public ».
  • Scannez à nouveau le code QR : sur le téléphone, ⋯ → Scanner un code QR.
  • Téléphone perdu ? Dans le logiciel, Paramètres → Renouveler la clé d’association. L'ancienne association cesse de fonctionner.

Avertissement « Versions incompatibles »

Mettez à jour le logiciel du PC et l'application du téléphone vers la même version. Le logiciel trouve seul les nouvelles versions ; si vous ne voulez pas attendre, utilisez Paramètres → Rechercher des mises à jour.

Windows indique qu'il « a protégé votre ordinateur »

Informations complémentaires → Exécuter quand même. Les détails et la façon de vérifier le fichier se trouvent dans le guide d'installation.

Les voyants des touches ETS2 ne s'allument pas

Le plugin est-il installé ? Paramètres → Jeux (ETS2 / ATS). Si oui, redémarrez le jeu et cliquez sur OK dans l'avis sur les « fonctions SDK avancées ».

OBS ne se connecte pas

OBS est-il ouvert, son serveur WebSocket est-il activé, et le port et le mot de passe sont-ils corrects ? Détails dans le guide OBS.

Discord ne m'entend pas

Dans Discord, choisissez comme périphérique d'entrée celui indiqué par l'assistant Configurer pour Discord, puis lancez l'étape Tester de l'assistant.

Toujours bloqué ?

Dans le logiciel, Signaler un problème… crée un paquet de diagnostic (zip) ; la clé d'association et les mots de passe en sont exclus. Envoyez-le par e-mail à admin@paneldeck.info avec une brève description du problème.
