🖥️ Second écran et connexion à distance

Affichez un moniteur sur le téléphone et connectez-vous hors de chez vous en données mobiles.

Second écran (Pro)

  1. Dans le logiciel, ouvrez Paramètres → la carte Second écran et cochez Second écran : diffuser le moniteur sur le téléphone.
  2. Pour l'utiliser au toucher, activez aussi Utiliser le téléphone comme souris (tactile) et clavier.
  3. Sur le téléphone, ouvrez ⋯ → Second écran.

Avec plusieurs moniteurs, vous pouvez choisir lequel s'affiche sur le téléphone. L'image n'est envoyée qu'à votre téléphone associé et n'est jamais enregistrée.

Connexion à distance (données mobiles)

  • Sans Wi‑Fi commun, le téléphone se connecte via le relais de PanelDeck. Rien à configurer ; la connexion est chiffrée de bout en bout et le relais ne peut pas voir le contenu.
  • En données mobiles, le second écran fonctionne en basse qualité (jusqu'à 4 images par seconde) et une session dure au maximum 20 minutes ; vous pouvez la rouvrir. L'application vous avertit à chaque fois de la consommation de données.
  • Pour la désactiver, décochez Connexion à distance : se connecter aussi via les données mobiles dans la carte Paramètres → Connexion sans fil du logiciel.
Les frais de données mobiles relèvent de vous et de votre opérateur. Pour de longues sessions de second écran, préférez le Wi‑Fi.
