Nouveautés

Ce qui a changé dans chaque version. Le logiciel et l'application trouvent seuls les nouvelles versions.

Version 0.16.3

  • ✉ Assistance par e-mail : admin@paneldeck.info. Le paquet de « Signaler un problème… » peut être joint à un e-mail ; pas besoin de compte GitHub
  • 📖 Le lien « Guides » ouvre désormais les guides pas à pas du site dans la langue du logiciel (13 langues)
  • 🌐 Le site a une nouvelle adresse : www.paneldeck.info. Les liens du logiciel y mènent

Version 0.16.2

  • 🧪 Les fonctions pas encore testées en conditions réelles sont désormais en « Bêta » : Twitch, l'import Stream Deck, l'assistant de configuration Discord et les alertes par vibration apparaissent quand Paramètres → Fonctions expérimentales (Bêta) est activé. Vos boutons existants continuent de fonctionner
  • 🔒 La galerie de profils et Elgato Key Light sont « bientôt disponibles » jusqu'à ce qu'ils soient testés
  • 🛠 Extensions : l'espace avant et après une valeur en direct est désormais conservé (par exemple « 4.3 km/h »)

Version 0.16.1

  • ⚡ Connexions plus robustes : les boutons de requête web, Twitch, les extensions et la recherche de mises à jour ne submergent plus les serveurs de requêtes répétées ; les mêmes informations sont mises en cache un court instant et une disposition inchangée n'est pas renvoyée dans le cloud
  • 🛠 Corrections : un seul bouton problématique n'interrompt plus toute l'importation Stream Deck ; la connexion à Twitch et les extensions gèrent mieux les erreurs réseau ; appuyer deux fois sur un bouton clip / publicité Twitch ne l'exécute plus deux fois
  • 📄 La politique de confidentialité et les conditions d'utilisation ont été mises à jour pour les nouvelles fonctions (Twitch, extensions, micro de réunion) : fenêtre À propos

Version 0.16.0

  • 🎨 Panneaux de programmes : pages de raccourcis prêtes pour Photoshop, Premiere Pro, After Effects, Illustrator, DaVinci Resolve, Blender, Figma et VS Code (Profil → Dispositions prêtes…). Quand le programme passe au premier plan, le téléphone propose de le configurer (Pro)
  • 🎙 Micro de réunion : un bouton qui coupe et rétablit votre micro dans Teams, Zoom, Meet, Webex et Slack sans raccourci, même quand la fenêtre est en arrière-plan ; un voyant sur le téléphone indique l'état
  • 🌍 8 nouvelles langues : russe, italien, français, néerlandais, indonésien, chinois, japonais et coréen (ordinateur et téléphone)
  • 🎛 Studio vocal (Pro) : 11 nouvelles voix, dont des voix naturelles de femme, d'homme, d'enfant et de personne âgée ; créez et enregistrez votre propre voix avec des curseurs ; noise gate et compresseur. Effets sonores → « Studio vocal… »
  • 📥 Importez votre profil Stream Deck : Profil → « Importer un profil Stream Deck… » (raccourcis, sites web, textes, actions multiples, dossiers et boutons OBS)
  • 📺 Twitch (Pro) : boutons pour les clips, marqueurs, publicités, messages de chat et modes de chat ; spectateurs, durée du live et abonnés en direct. Paramètres → Diffusion en direct : Twitch
  • 🧩 Extensions : ajoutez de nouveaux boutons prêts à l'emploi et des infos en direct avec des extensions d'un seul fichier. Paramètres → Extensions

Version 0.15.3

  • 📚 Guides : des guides pas à pas pour l’installation, ETS2 / ATS, OBS, Discord et le dépannage sur le site, en 5 langues. Ouvrez-les depuis la fenêtre À propos ou Paramètres → Général

Version 0.15.2

  • 📖 Nouvelle fenêtre « À propos » : les conditions d’utilisation, la politique de confidentialité et les licences open source sont maintenant dans le programme, sans internet (cliquez sur le texte de version en bas à gauche)

Version 0.15.1

  • 📄 Conditions d’utilisation, politique de confidentialité et licences open source : en bas de Paramètres → Général

Version 0.15.0

  • 🖼 Vrais logos : les boutons comme Discord, Steam, YouTube et WhatsApp affichent le logo propre du programme ou du site (appliqué une fois aux boutons existants)
  • 📳 Alertes par vibration (Pro) : limitation de vitesse, carburant et dégâts dans ETS2/ATS ; saturation, images perdues et chutes de débit dans les streams OBS
  • 🎮 Zéro configuration : quand un jeu démarre, le téléphone propose de configurer son panneau prêt à l’emploi, puis y passe tout seul
  • 🧪 La prise en charge de la course et du vol se trouve désormais derrière l’interrupteur « Fonctions expérimentales (Bêta) » (Paramètres)

Version 0.14.1

  • 🎨 La barre de titre de la fenêtre est maintenant assortie à l’interface bleu nuit : plus de bande blanche
  • 🛠 Sauvegarde cloud : les anciennes sauvegardes ne sont proposées que sur un ordinateur fraîchement installé

Version 0.14.0

  • ☁ Sauvegarde cloud (Pro) : votre disposition est stockée chiffrée ; si Windows est réinstallé ou si vous changez d’ordinateur, elle revient avec votre téléphone. Paramètres → Sauvegarde cloud

Version 0.13.3

  • ✨ Nouveau look : le thème Nuit et or. Pour assortir aussi les boutons : Profil → « Assortir les couleurs au thème Nuit »
  • 📡 Le second écran s’ouvre maintenant aussi via les données mobiles (connexion à distance) : basse qualité, quelques images par seconde, 20 minutes par session
  • 🛠 La configuration automatique de l’écran latéral ETS2 / ATS a été retirée : le jeu ne s’étend pas sur des moniteurs séparés, l’image était écrasée sur l’écran principal. Si vous l’avez utilisée : Paramètres → Jeux → « Annuler la configuration de l’écran latéral… »

Version 0.13.2

  • 👈 Regarder à gauche / droite se verrouille maintenant d’un seul toucher ; « 🎯 Regarder devant » revient à la vue principale
  • 📱 Nouvelle carte « Faire du téléphone un moniteur supplémentaire » sur la page Second écran : écran latéral ETS2 / ATS en un clic

Version 0.13.1

  • 📱 Utiliser le téléphone comme écran latéral dans le jeu (ETS2 / ATS, expérimental) : Paramètres → Jeux → « Utiliser le téléphone comme écran latéral dans le jeu… »
  • 🖥 Second écran : nouveau menu d’options, moniteurs par nom de modèle ; un moniteur virtuel apparaît comme « écran du téléphone / de la tablette »
  • 🚦 Vraies icônes de voyants du tableau de bord sur les boutons du camion et le tableau de bord ; un nouvel écran Pro ; une suggestion de grille plus large sur les tablettes

Version 0.13.0

  • 🌍 Connexion à distance : le téléphone se connecte aussi via les données mobiles ou un autre Wi‑Fi ; ni Tailscale, ni configuration du routeur, ni installation nécessaires (chiffrement de bout en bout)
  • ⏱ Bouton minuteur : touchez pour lancer un compte à rebours, le temps restant s’affiche sur le bouton ; à la fin, le téléphone vibre et bipe et le PC joue une alerte (prêts à l’emploi : Concentration 25 min, Pause 5 min)
  • 💾 Sauvegarde automatique : votre disposition est sauvegardée chaque jour et avant de grosses suppressions ; revenez en arrière en un clic avec Profil → Sauvegardes automatiques…
  • ✈ X-Plane 11 / 12 : boutons pour les feux, le train d’atterrissage, les volets, le frein de parking et le pilote automatique (leurs voyants affichent l’état dans X-Plane) et jauges pour la vitesse, l’altitude, la vitesse verticale, le cap et le carburant ; disposition prête : Vol
  • 💻 Plusieurs ordinateurs : le téléphone se souvient de chaque PC associé ; changez avec ⋯ → Ordinateurs sur le téléphone
  • 🏎 Tableau de bord de course : rapport, voyants de passage, temps au tour, position et carburant en plein écran sur le téléphone pour Forza Horizon / Motorsport, F1 23-25, BeamNG et Assetto Corsa ; disposition prête : Jeux de course
  • 📦 Galerie de profils : importez en un clic des profils prêts à l’emploi partagés par d’autres avec Profil → Galerie de profils…
  • ✨ Cette fenêtre « Nouveautés » : affiche ce qui a changé après une mise à jour

Anciennes versions et tous les fichiers : page des versions sur GitHub.
