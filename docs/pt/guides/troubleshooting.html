🛠️ Solução de problemas

Soluções rápidas para problemas de conexão, versão, ETS2, OBS e Discord.

O celular não conecta

  • O PC e o celular estão no mesmo Wi‑Fi? Se não, o celular se conecta remotamente por dados móveis, o que pode levar alguns segundos.
  • No programa, Acesso sem fio (Wi‑Fi) na mesma rede precisa estar ativado (cartão Configurações → Conexão sem fio).
  • Se o Firewall do Windows perguntou, permita tanto as redes privadas quanto as públicas.
  • Leia o código QR de novo: no celular, ⋯ → Ler código QR.
  • Perdeu o celular? No programa, Configurações → Renovar chave de pareamento. O pareamento antigo deixa de funcionar.

Aviso “Versões incompatíveis”

Atualize o programa do PC e o app do celular para a mesma versão. O programa encontra as versões novas sozinho; se não quiser esperar, use Configurações → Verificar atualizações agora.

O Windows diz que “protegeu o computador”

Mais informações → Executar assim mesmo. Os detalhes e como verificar o arquivo estão no guia de instalação (em inglês).

As luzes dos botões do ETS2 não acendem

O plugin está instalado? Configurações → Jogos (ETS2 / ATS). Se estiver, reinicie o jogo e confirme o aviso sobre “recursos avançados do SDK”.

O OBS não conecta

O OBS está aberto, o servidor WebSocket está ativado e a porta e a senha estão certas? Detalhes no guia do OBS.

No Discord ninguém me ouve

No Discord, escolha como dispositivo de entrada o dispositivo mostrado pelo assistente Configurar para o Discord e execute o passo Testar do assistente.

Ainda não resolveu?

No programa, Relatar um problema… cria um pacote de diagnóstico (zip); a chave de pareamento e as senhas ficam de fora. Anexe-o a um tópico novo na página de suporte.
