🖥️ Segunda tela e conexão remota

Leve o monitor para o celular e conecte por dados móveis quando estiver fora.

Segunda tela (Pro)

  1. No programa, abra Configurações → o cartão Segunda tela e marque Segunda tela: transmitir o monitor para o celular.
  2. Para usar com toques, ative também Deixar o celular funcionar como mouse (toque) e teclado.
  3. No celular, abra ⋯ → Segunda tela.

Se você tiver mais de um monitor, pode escolher qual aparece no celular. A imagem vai só para o seu celular pareado e não é gravada.

Conexão remota (dados móveis)

  • Sem Wi‑Fi em comum, o celular se conecta pelo servidor intermediário do PanelDeck. Não há nada para configurar; a conexão tem criptografia de ponta a ponta e o servidor não vê o conteúdo.
  • Nos dados móveis, a segunda tela roda em baixa qualidade (até 4 quadros por segundo) e cada sessão dura no máximo 20 minutos; você pode abrir de novo. O app avisa sobre o consumo de dados toda vez.
  • Para desligar, desmarque Conexão remota: conectar também por dados móveis no cartão Configurações → Conexão sem fio do programa.
As cobranças de dados móveis são entre você e sua operadora. Para sessões longas de segunda tela, prefira o Wi‑Fi.
