更新内容

每个版本的变化。程序和应用会自动发现新版本。

版本 0.16.3

  • ✉ 支持改为电子邮件：admin@paneldeck.info。“报告问题…”生成的诊断包可作为邮件附件发送，无需 GitHub 账号
  • 📖 “指南”链接现在会以程序的语言打开网站上的分步指南（13 种语言）
  • 🌐 网站新地址：www.paneldeck.info。程序中的链接都指向这里

版本 0.16.2

  • 🧪 尚未在实际使用中测试的功能现在标为“Beta”：开启 设置 → 实验性功能（Beta）后才会显示 Twitch、Stream Deck 导入、Discord 设置向导和振动提醒。已有的按钮会继续工作
  • 🔒 配置文件库和 Elgato Key Light 在测试完成前标为“即将推出”
  • 🛠 插件：实时数值前后的空格现在会保留（例如“4.3 km/h”）

版本 0.16.1

  • ⚡ 连接更稳健：网页请求按钮、Twitch、插件和更新检查不再向服务器重复发送请求；相同的信息会短暂缓存，未更改的布局不会再次上传到云端
  • 🛠 修复：单个有问题的按钮不再中断整个 Stream Deck 导入；Twitch 登录和插件能更好地处理网络错误；连按两次 Twitch 剪辑 / 广告按钮不会再执行两次
  • 📄 隐私政策和使用条款已根据新功能（Twitch、插件、会议麦克风）更新：“关于”窗口

版本 0.16.0

  • 🎨 程序面板：为 Photoshop、Premiere Pro、After Effects、Illustrator、DaVinci Resolve、Blender、Figma 和 VS Code 准备好的快捷键页面（配置文件 → 现成布局…）。程序切换到前台时，手机会提议进行设置（Pro）
  • 🎙 会议麦克风：无需快捷键即可在 Teams、Zoom、Meet、Webex 和 Slack 中静音和取消静音的按钮，窗口在后台时也有效；手机上的指示灯显示状态
  • 🌍 8 种新语言：俄语、意大利语、法语、荷兰语、印度尼西亚语、中文、日语和韩语（电脑和手机）
  • 🎛 声音工作室（Pro）：11 种新声音，包括自然的女声、男声、童声和老年声；用滑块创建并保存自己的声音；噪声门和压缩器。音效 →“声音工作室…”
  • 📥 导入你的 Stream Deck 配置文件：配置文件 →“导入 Stream Deck 配置文件…”（快捷键、网站、文本、多重操作、文件夹和 OBS 按钮）
  • 📺 Twitch（Pro）：剪辑、直播标记、广告、聊天消息和聊天模式按钮；实时显示观众数、直播时长和关注者。设置 → 直播：Twitch
  • 🧩 插件：用单文件插件添加新的现成按钮和实时信息。设置 → 插件

版本 0.15.3

  • 📚 指南：网站上提供设置、ETS2 / ATS、OBS、Discord 和故障排除的分步指南，共 5 种语言。可从“关于”窗口或“设置 → 常规”打开

版本 0.15.2

  • 📖 新的“关于”窗口：使用条款、隐私政策和开源许可证现在都在程序内，无需联网（点击左下角的版本文字）

版本 0.15.1

  • 📄 使用条款、隐私政策和开源许可证：位于“设置 → 常规”底部

版本 0.15.0

  • 🖼 真实标志：Discord、Steam、YouTube、WhatsApp 等按钮会显示程序或网站自己的标志（已对现有按钮应用一次）
  • 📳 振动提醒（Pro）：ETS2/ATS 中的限速、燃油和损坏；OBS 直播中的拥塞、丢帧和码率下降
  • 🎮 零设置：游戏启动时，手机会提议设置其现成面板，之后自动切换过去
  • 🧪 赛车和飞行支持现在位于“实验性功能（Beta）”开关之后（设置）

版本 0.14.1

  • 🎨 窗口标题栏现在与深蓝色界面一致：不再有白色条
  • 🛠 云备份：只在新安装的电脑上提供旧备份

版本 0.14.0

  • ☁ 云备份（Pro）：你的布局会加密存储；重装 Windows 或更换电脑后，可通过手机找回。设置 → 云备份

版本 0.13.3

  • ✨ 新外观：“夜间与金色”主题。若要让按钮也匹配：配置文件 → “让颜色匹配‘夜间’主题”
  • 📡 第二屏幕现在也可以通过移动数据打开（远程连接）：低画质，每秒几帧，每次 20 分钟
  • 🛠 已移除 ETS2 / ATS 侧屏自动设置：游戏不会横跨多个独立显示器，画面会被压缩到主屏幕上。如果你用过：设置 → 游戏 → “撤销侧屏设置…”

版本 0.13.2

  • 👈 向左 / 向右看现在只需点按一次即可锁定；“🎯 向前看”返回主视角
  • 📱 第二屏幕页面上新增“让手机成为额外显示器”卡片：一键设置 ETS2 / ATS 侧屏

版本 0.13.1

  • 📱 在游戏中将手机用作侧屏（ETS2 / ATS，实验性）：设置 → 游戏 → “在游戏中将手机用作侧屏…”
  • 🖥 第二屏幕：新的选项菜单，按型号名称显示显示器；虚拟显示器显示为“手机 / 平板屏幕”
  • 🚦 卡车按钮和仪表盘上使用真实的仪表指示灯图标；新的 Pro 界面；平板上建议使用更宽的网格

版本 0.13.0

  • 🌍 远程连接：手机也可以通过移动数据或其他 Wi‑Fi 连接；无需 Tailscale、路由器设置或额外安装（端到端加密）
  • ⏱ 计时器按钮：点按开始倒计时，剩余时间显示在按钮上；时间到时手机会振动并发出提示音，PC 会播放提醒（现成：专注 25 分钟、休息 5 分钟）
  • 💾 自动备份：每天以及大量删除之前都会备份你的布局；通过“配置文件 → 自动备份…”一键恢复
  • ✈ X-Plane 11 / 12：灯光、起落架、襟翼、停机刹车和自动驾驶按钮（指示灯显示 X-Plane 中的状态），以及速度、高度、垂直速度、航向和燃油仪表；现成布局：飞行
  • 💻 多台电脑：手机会记住每台配对过的 PC；在手机上通过 ⋯ → 电脑 切换
  • 🏎 赛车仪表盘：在手机上全屏显示 Forza Horizon / Motorsport、F1 23-25、BeamNG 和 Assetto Corsa 的挡位、换挡灯、圈速、名次和燃油；现成布局：赛车游戏
  • 📦 配置文件库：通过“配置文件 → 配置文件库…”一键导入他人分享的现成配置文件
  • ✨ 这个“新功能”窗口：显示更新后有哪些变化

旧版本及所有文件：GitHub 发布页面。
