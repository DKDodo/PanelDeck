📲 安装与连接

安装程序和应用，然后用二维码连接手机。

PanelDeck 由两部分组成：Windows 程序和 Android 应用。两者需要保持相同版本；程序会自动发现新版本。

1. 在电脑上安装程序

  1. 下载并运行 PanelDeck 安装程序。无需管理员权限。
  2. 如果 Windows 提示“已保护你的电脑”，点击更多信息 → 仍要运行。详见安装指南。
  3. 首次启动时，程序会打开连接你的手机向导。

2. 在手机上安装应用

  1. 用手机相机扫描向导中的下载二维码。
  2. 点按下载好的 UsbDeck.apk 文件。
  3. 如果 Android 询问，开启允许来自此来源的应用，然后点按安装。无需开发者模式。

3. 配对（Wi‑Fi，推荐）

  1. 确保电脑和手机连接在同一个 Wi‑Fi 网络。
  2. 在手机上打开 PanelDeck，点按用二维码连接，然后扫描电脑上的二维码。
  3. 点按配对。如果 Windows 防火墙询问，请同时允许“专用”和“公用”网络。

以后如需再次打开向导，请使用程序顶栏的 ＋ 添加手机 按钮。

通过 USB 连接（高级）

使用数据线连接时，需要在手机的开发者选项中开启 USB 调试。向导的 USB 部分会显示操作步骤和实时连接状态。

出门在外

配对后，没有共同 Wi‑Fi 时手机也会通过移动数据连接；无需任何设置，连接采用端到端加密。详见第二屏幕与远程连接指南。

首次布局可在 配置文件 → 现成布局… 中选择“主播”“玩家”“办公”或“卡车驾驶”；你的程序会自动添加真实图标。
