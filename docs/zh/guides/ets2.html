🚚 ETS2 与 ATS

安装插件：实时仪表盘、指示灯和振动。

对于 Euro Truck Simulator 2 和 American Truck Simulator，PanelDeck 会在按键上添加显示游戏状态的指示灯，并在手机上提供实时仪表盘。

1. 安装插件

  1. 在程序中打开设置 → 游戏（ETS2 / ATS）卡片，点击安装插件。一个小型遥测插件会被复制到游戏文件夹（开源，MIT）。
  2. 重启游戏。每次启动时游戏都会显示“高级 SDK 功能”提示：点击 OK。

2. 添加现成面板

在程序中：配置文件 → 现成布局… → 卡车驾驶（ETS2 / ATS） → 使用。使用 Pro 更简单：游戏启动时，手机会推荐现成面板；接受后，每次游戏启动手机都会自动切换到该页面。

3. 仪表盘与提醒

  • 仪表盘按键会在手机上打开全屏仪表盘：车速、限速、转速、油量、预计到达时间和指示灯。
  • 车灯、驻车制动和定速巡航按键会随游戏状态亮起；向左或向右看只需点按一次即可锁定。
  • 振动提醒（Beta，Pro）：超速、油量不足或出现新损坏时手机会振动。需在程序的设置中开启实验性功能（Beta）才能使用。如需关闭，请在手机上打开 ⋯ → 设置 → 游戏和直播提醒。
按键发送的是游戏的默认按键。如果你在游戏中改过按键，请在程序中选中该按键并更新其游戏内按键字段。
