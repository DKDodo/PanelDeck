🛠️ 故障排除

连接、版本、ETS2、OBS 和 Discord 问题的快速解决方法。

手机无法连接

  • 电脑和手机在同一个 Wi‑Fi 吗？如果不在，手机会通过移动数据远程连接，可能需要几秒钟。
  • 程序中需开启同一网络下的无线访问（Wi‑Fi）（设置 → 无线连接卡片）。
  • 如果 Windows 防火墙询问过，请同时允许“专用”和“公用”网络。
  • 重新扫描二维码：在手机上 ⋯ → 扫描二维码。
  • 手机丢了？在程序中 设置 → 更新配对密钥。旧的配对将失效。

“版本不一致”警告

将电脑程序和手机应用更新到相同版本。程序会自动发现新版本；如果不想等待，请使用设置 → 立即检查更新。

Windows 提示“已保护你的电脑”

更多信息 → 仍要运行。详细说明及如何校验文件，请参阅安装指南。

ETS2 按键指示灯不亮

插件安装了吗？设置 → 游戏（ETS2 / ATS）。如已安装，请重启游戏，并在“高级 SDK 功能”提示中点击 OK。

OBS 无法连接

OBS 是否已打开、WebSocket 服务器是否已开启、端口和密码是否正确？详见 OBS 指南。

Discord 听不到我的声音

在 Discord 中把为 Discord 设置向导显示的设备选为输入设备，然后运行向导中的测试步骤。

仍未解决？

在程序中，报告问题…会生成诊断包（zip），其中不包含配对密钥和密码。请将它连同问题的简要说明发送到 admin@paneldeck.info。
