🎧 Discord 与音效

把变声后的声音和现成音效发送到 Discord。

变声器和现成音效可以只播放给你自己，也可以播放给 Discord 上的朋友。要把声音发送到 Discord，你的麦克风会通过免费的虚拟音频线 Voicemeeter 接入 Discord。

1. 设置向导（Beta）

  1. 该向导处于测试阶段：请先在程序的设置中开启实验性功能（Beta），然后打开音效页面，点击🎧 为 Discord 设置（Beta）。
  2. 向导会按顺序显示各个步骤；大多数只需点一下。如果没有安装 Voicemeeter，向导会打开下载页面。
  3. 在 Discord 中打开设置 → 语音和视频，把向导显示的设备选为输入设备；该步骤会自动变为 ✓。
  4. 使用向导中的测试，用一段短提示音检查整条链路。撤销会恢复向导修改过的 Voicemeeter 设置。

2. 谁能听到？

仅我自己、Discord 上的所有人或我和 Discord。变声器和现成音效分别选择。

3. 效果和音效

  • 变声器：低沉嗓音、尖细嗓音、怪物、外星人、机器人、回声、洞穴、无线电。
  • 现成音效：用＋ 添加声音…添加你自己的 .wav 文件，或使用✨ 添加现成音效；通过作为按钮添加到面板放到手机上。
关闭 Discord 麦克风或耳机无需设置快捷键：只要 Discord 在语音频道中，现成的 Discord 麦克风和 Discord 拒听按键即可直接使用。
