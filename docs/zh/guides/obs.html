🎥 OBS Studio

开启 WebSocket：场景、录制、推流和直播状态提醒。

PanelDeck 通过 OBS 自带的 WebSocket 连接 OBS Studio：从手机切换场景、录制、推流、保存片段并控制音频源。

1. 在 OBS 中开启 WebSocket

  1. 在 OBS 中：工具 → WebSocket 服务器设置 → 开启 WebSocket 服务器。
  2. 记下端口（默认 4455）和密码。

2. 连接 PanelDeck

  1. 在程序中打开设置 → OBS Studio 卡片，勾选从手机控制 OBS（场景、录制、直播、音频）。
  2. 输入服务器 127.0.0.1、端口 4455 和 OBS 密码，然后点击保存。OBS 关闭期间，程序会每隔几秒重试一次。

3. 添加按键

选中一个按键，从现成操作列表的 OBS 部分选择场景、录制、推流、片段或音频源操作。录制和推流计时器会直接显示在按键上。现成的主播布局已包含其中大部分按键。

直播状态提醒（Beta，Pro）

出现拥塞、丢帧或码率下降时，手机会振动并在屏幕顶部显示一条彩色横条。需在程序的设置中开启实验性功能（Beta）才能使用。如需关闭，请在设置 → OBS Studio 卡片中取消勾选直播出现问题时手机振动提醒。
