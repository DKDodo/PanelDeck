🚚 ETS2 と ATS

プラグインをインストール：ライブダッシュボード、警告灯、振動。

Euro Truck Simulator 2 と American Truck Simulator では、PanelDeck がボタンにゲーム内の状態を示すランプを追加し、スマホにライブダッシュボードを表示します。

1. プラグインをインストール

  1. プログラムで設定 → ゲーム（ETS2 / ATS）カードを開き、プラグインをインストールをクリックします。小さなテレメトリープラグインがゲームフォルダーにコピーされます（オープンソース、MIT）。
  2. ゲームを再起動します。起動のたびに「高度な SDK 機能」の通知が表示されるので、OK をクリックします。

2. 既製のパネルを追加

プログラムで：プロファイル → 既製のレイアウト… → トラック運転（ETS2 / ATS） → 使用。Pro ならさらに簡単です。ゲームを起動するとスマホが既製のパネルを提案し、承認すれば以降はゲームを起動するたびにそのページへ切り替わります。

3. ダッシュボードとアラート

  • ダッシュボードボタンでスマホに全画面のダッシュボードが開きます：速度、制限速度、回転数、燃料、到着時刻、警告灯。
  • ライト、パーキングブレーキ、クルーズコントロールのボタンはゲーム内の状態に合わせて点灯します。左右を見る操作はワンタップで固定されます。
  • 振動アラート（ベータ、Pro）：制限速度の超過、燃料不足、新しい損傷のときにスマホが振動します。プログラムの設定で実験的な機能（ベータ）がオンのときに動作します。オフにするには、スマホで ⋯ → 設定 → ゲームと配信のアラートを開きます。
ボタンはゲームの既定のキーを送ります。ゲーム内でキーを変更した場合は、プログラムでボタンを選び、ゲーム内のキー欄を更新してください。
