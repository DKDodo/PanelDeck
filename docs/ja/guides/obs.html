🎥 OBS Studio

WebSocket を有効化：シーン、録画、配信、配信状態の通知。

PanelDeck は OBS 自身の WebSocket を通じて OBS Studio に接続します。スマホからシーンの切り替え、録画、配信、クリップの保存、音声ソースの操作ができます。

1. OBS で WebSocket をオンにする

  1. OBS で：ツール → WebSocket サーバー設定 → WebSocket サーバーを有効にする。
  2. ポート（既定は 4455）とパスワードを控えておきます。

2. PanelDeck を接続

  1. プログラムで設定 → OBS Studioカードを開き、スマホから OBS を操作（シーン、録画、配信、音声）にチェックを入れます。
  2. サーバー 127.0.0.1、ポート 4455、OBS のパスワードを入力して保存をクリックします。OBS が閉じている間、プログラムは数秒ごとに再試行します。

3. ボタンを追加

ボタンを選び、既製のアクションリストの OBS セクションからシーン、録画、配信、クリップ、音声ソースのアクションを選びます。録画と配信のタイマーはボタン上に直接表示されます。既製の配信者レイアウトには、これらのボタンのほとんどが最初から含まれています。

配信状態のアラート（ベータ、Pro）

混雑、フレーム落ち、ビットレートの低下が起きると、スマホが振動し、画面上部に色付きの帯が表示されます。プログラムの設定で実験的な機能（ベータ）がオンのときに動作します。オフにするには、設定 → OBS Studioカードの配信トラブル時のスマホ振動アラートのチェックを外します。
