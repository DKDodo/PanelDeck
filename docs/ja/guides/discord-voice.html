🎧 Discord と効果音

加工した声や既製のサウンドを Discord に送ります。

ボイスチェンジャーと既製のサウンドは、自分だけに流すことも、Discord の友だちに届けることもできます。Discord に音を送るため、マイクは無料の仮想オーディオケーブル Voicemeeter を通して Discord に送られます。

1. セットアップウィザード（ベータ）

  1. このウィザードはベータ版です。まずプログラムの設定で実験的な機能（ベータ）をオンにし、サウンドエフェクトページを開いて🎧 Discord 用に設定（ベータ）をクリックします。
  2. ウィザードが手順を順番に表示します。ほとんどはワンクリックで済みます。Voicemeeter がインストールされていなければ、ダウンロードページを開きます。
  3. Discord で設定 → 音声・ビデオを開き、ウィザードが示すデバイスを入力デバイスに選びます。その手順は自動で ✓ になります。
  4. ウィザードのテストで、短い音を使って全体の経路を確認します。元に戻すは、ウィザードが変更した Voicemeeter の設定を元に戻します。

2. 誰に聞こえるようにする？

自分だけ、Discord の全員、自分と Discord から選びます。ボイスチェンジャーと既製のサウンドで別々に選べます。

3. エフェクトとサウンド

  • ボイスチェンジャー：低い声、高い声、モンスター、エイリアン、ロボット、エコー、洞窟、ラジオ。
  • 既製のサウンド：＋ サウンドを追加…で自分の .wav ファイルを追加するか、✨ 既製のサウンドを追加を使います。ボタンとしてパネルに追加でスマホに置けます。
Discord のマイクやスピーカーをミュートするのにショートカットを割り当てる必要はありません。Discord がボイスチャンネルにいる間は、既製の Discord マイクと Discord スピーカーミュートボタンがそのまま使えます。
