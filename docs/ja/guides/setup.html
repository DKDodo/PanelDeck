📲 インストールと接続

プログラムとアプリをインストールし、QR コードでスマホを接続します。

PanelDeck は Windows 用プログラムと Android アプリの 2 つで構成されています。両方を同じバージョンにしてください。プログラムは新しいバージョンを自動で見つけます。

1. PC にプログラムをインストール

  1. PanelDeck インストーラーをダウンロードして実行します。管理者権限は不要です。
  2. Windows に「PC を保護しました」と表示されたら、詳細情報 → 実行をクリックします。詳しくはインストールガイドをご覧ください。
  3. 初回起動時、プログラムはスマホを接続ウィザードを開きます。

2. スマホにアプリをインストール

  1. ウィザードのダウンロード用コードをスマホのカメラでスキャンします。
  2. ダウンロードした UsbDeck.apk ファイルをタップします。
  3. Android に確認されたらこの提供元のアプリを許可をオンにし、インストールをタップします。開発者モードは不要です。

3. ペアリング（Wi‑Fi、推奨）

  1. PC とスマホが同じ Wi‑Fi ネットワークにあることを確認します。
  2. スマホで PanelDeck を開き、QR コードで接続をタップして PC のコードをスキャンします。
  3. ペアリングをタップします。Windows ファイアウォールに確認されたら、「プライベート」と「パブリック」の両方のネットワークを許可してください。

あとでウィザードを再び開くには、プログラム上部の ＋ スマホを追加 ボタンを使います。

USB で接続（上級者向け）

ケーブルで接続するには、スマホの開発者向けオプションで USB デバッグをオンにする必要があります。ウィザードの USB セクションに手順とリアルタイムの接続状態が表示されます。

外出先で

ペアリング後は、共通の Wi‑Fi がないときもスマホはモバイルデータで接続します。設定は不要で、接続はエンドツーエンドで暗号化されます。詳しくはセカンドスクリーンとリモート接続ガイドをご覧ください。

最初のレイアウトには、プロファイル → 既製のレイアウト… で「配信者」「ゲーマー」「オフィス」「トラック運転」のいずれかを選びましょう。プログラムの本物のロゴが自動で追加されます。
