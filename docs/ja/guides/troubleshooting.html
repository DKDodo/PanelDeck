🛠️ トラブルシューティング

接続、バージョン、ETS2、OBS、Discord の問題をすばやく解決。

スマホが接続しない

  • PC とスマホは同じ Wi‑Fi にありますか？ そうでなければ、スマホはモバイルデータでリモート接続します。数秒かかることがあります。
  • プログラムで同じネットワークでのワイヤレスアクセス（Wi‑Fi）がオンになっている必要があります（設定 → ワイヤレス接続カード）。
  • Windows ファイアウォールに確認された場合は、「プライベート」と「パブリック」の両方のネットワークを許可してください。
  • QR コードをもう一度スキャンします：スマホで ⋯ → QR コードをスキャン。
  • スマホをなくしたら？ プログラムで設定 → ペアリングキーを更新。古いペアリングは使えなくなります。

「バージョンの不一致」の警告

PC のプログラムとスマホのアプリを同じバージョンに更新してください。プログラムは新しいバージョンを自動で見つけます。待ちたくない場合は設定 → 今すぐ更新を確認を使います。

Windows に「PC を保護しました」と表示される

詳細情報 → 実行。詳しい説明とファイルの確認方法はインストールガイドにあります。

ETS2 のボタンのランプが点かない

プラグインはインストールされていますか？ 設定 → ゲーム（ETS2 / ATS）。インストール済みなら、ゲームを再起動して「高度な SDK 機能」の通知で OK をクリックしてください。

OBS が接続しない

OBS は開いていますか？ WebSocket サーバーは有効になっていて、ポートとパスワードは正しいですか？ 詳しくは OBS ガイドをご覧ください。

Discord で声が届かない

Discord で、Discord 用に設定ウィザードが示すデバイスを入力デバイスに選び、ウィザードのテスト手順を実行してください。

それでも解決しない場合

プログラムの問題を報告…で診断パッケージ（zip）が作成されます。ペアリングキーとパスワードは含まれません。問題の簡単な説明を添えて admin@paneldeck.info までメールでお送りください。
