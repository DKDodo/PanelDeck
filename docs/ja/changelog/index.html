新機能

各バージョンの変更点。プログラムとアプリは新しいバージョンを自動で見つけます。

バージョン 0.16.2

  • 🧪 まだ実際の使用でテストされていない機能は「ベータ」になりました：Twitch、Stream Deck の取り込み、Discord 設定ウィザード、振動アラートは 設定 → 実験的な機能（ベータ）がオンのときに表示されます。既存のボタンはそのまま動作します
  • 🔒 プロファイルギャラリーと Elgato Key Light は、テストが済むまで「近日公開」です
  • 🛠 プラグイン：ライブ値の前後の空白が保持されるようになりました（例：「4.3 km/h」）

バージョン 0.16.1

  • ⚡ より安定した接続：Web リクエストボタン、Twitch、プラグイン、更新チェックがサーバーに同じリクエストを繰り返し送らなくなりました。同じ情報は短時間キャッシュされ、変更のないレイアウトはクラウドに再アップロードされません
  • 🛠 修正：問題のあるボタンが一つあっても Stream Deck の取り込み全体が止まらなくなりました。Twitch のサインインとプラグインがネットワークエラーに強くなりました。Twitch のクリップ / CM ボタンを二度押しても二回実行されません
  • 📄 プライバシーポリシーと利用規約を新機能（Twitch、プラグイン、会議用マイク）に合わせて更新しました：「バージョン情報」ウィンドウ

バージョン 0.16.0

  • 🎨 アプリパネル：Photoshop、Premiere Pro、After Effects、Illustrator、DaVinci Resolve、Blender、Figma、VS Code 用のショートカットページ（プロファイル → 既製のレイアウト…）。アプリが前面に来ると、スマホがセットアップを提案します（Pro）
  • 🎙 会議用マイク：Teams、Zoom、Meet、Webex、Slack でショートカットなしにマイクをミュート・解除するボタン。ウィンドウが背面にあっても動作し、スマホのランプで状態がわかります
  • 🌍 8 つの新しい言語：ロシア語、イタリア語、フランス語、オランダ語、インドネシア語、中国語、日本語、韓国語（パソコンとスマホ）
  • 🎛 ボイススタジオ（Pro）：自然な女性・男性・子ども・高齢者の声を含む 11 種類の新しい声。スライダーで自分の声を作って保存。ノイズゲートとコンプレッサー。サウンドエフェクト →「ボイススタジオ…」
  • 📥 Stream Deck のプロファイルを取り込めます：プロファイル →「Stream Deck のプロファイルをインポート…」（ショートカット、サイト、テキスト、マルチアクション、フォルダー、OBS ボタン）
  • 📺 Twitch（Pro）：クリップ、マーカー、CM、チャットメッセージ、チャットモードのボタン。視聴者数・配信時間・フォロワー数をライブ表示。設定 → ライブ配信：Twitch
  • 🧩 プラグイン：単一ファイルのプラグインで、新しい既製ボタンやライブ情報を追加できます。設定 → プラグイン

バージョン 0.15.3

  • 📚 ガイド：セットアップ、ETS2 / ATS、OBS、Discord、トラブルシューティングの手順ガイドを Web サイトに 5 言語で用意しました。「バージョン情報」ウィンドウまたは「設定 → 全般」から開けます

バージョン 0.15.2

  • 📖 新しい「バージョン情報」ウィンドウ：利用規約、プライバシーポリシー、オープンソースライセンスがプログラム内で読めるようになりました。インターネット不要です（左下のバージョン表示をクリック）

バージョン 0.15.1

  • 📄 利用規約、プライバシーポリシー、オープンソースライセンス：「設定 → 全般」の下部

バージョン 0.15.0

  • 🖼 本物のロゴ：Discord、Steam、YouTube、WhatsApp などのボタンに、プログラムやサイト自身のロゴを表示します（既存のボタンに一度適用）
  • 📳 振動アラート（Pro）：ETS2/ATS の制限速度、燃料、損傷。OBS 配信の混雑、ドロップフレーム、ビットレート低下
  • 🎮 設定不要：ゲームが起動すると、スマホが既製のパネルの設定を提案し、その後は自動で切り替わります
  • 🧪 レースとフライトのサポートは「実験的な機能（ベータ）」スイッチ（設定）の内側に移りました

バージョン 0.14.1

  • 🎨 ウィンドウのタイトルバーがネイビーのインターフェースに合うようになりました：白い帯はもうありません
  • 🛠 クラウドバックアップ：以前のバックアップは新しくインストールしたパソコンでのみ提案されます

バージョン 0.14.0

  • ☁ クラウドバックアップ（Pro）：レイアウトは暗号化して保存されます。Windows を再インストールしたりパソコンを買い替えたりしても、スマホで元に戻せます。設定 → クラウドバックアップ

バージョン 0.13.3

  • ✨ 新しい外観：ナイト＆ゴールドテーマ。ボタンも合わせるには：プロファイル → 「色をナイトテーマに合わせる」
  • 📡 セカンドスクリーンがモバイルデータ（リモート接続）でも開けるようになりました：低画質、毎秒数フレーム、一回 20 分
  • 🛠 ETS2 / ATS のサイド画面の自動設定は削除されました：ゲームは別々のモニターにまたがらず、映像がメイン画面に押し込まれていました。使用していた場合：設定 → ゲーム → 「サイド画面の設定を元に戻す…」

バージョン 0.13.2

  • 👈 左 / 右を見るはワンタップで固定されるようになりました。「🎯 前を見る」でメイン視点に戻ります
  • 📱 セカンドスクリーンページに新しいカード「スマホを追加モニターにする」：ワンクリックで ETS2 / ATS のサイド画面

バージョン 0.13.1

  • 📱 ゲームでスマホをサイド画面として使う（ETS2 / ATS、実験的）：設定 → ゲーム → 「ゲームでスマホをサイド画面として使う…」
  • 🖥 セカンドスクリーン：新しいオプションメニュー、モデル名でのモニター表示。仮想モニターは「スマホ / タブレットの画面」と表示されます
  • 🚦 トラックのボタンとダッシュボードに本物の警告灯アイコン。新しい Pro 画面。タブレットではより広いグリッドを提案

バージョン 0.13.0

  • 🌍 リモート接続：スマホはモバイルデータや別の Wi‑Fi でも接続します。Tailscale、ルーターの設定、インストールは不要です（エンドツーエンド暗号化）
  • ⏱ タイマーボタン：タップでカウントダウンを開始し、残り時間をボタンに表示します。時間になるとスマホが振動して音が鳴り、PC で通知音が再生されます（既製：集中 25 分、休憩 5 分）
  • 💾 自動バックアップ：レイアウトは毎日、また大量に削除する前にバックアップされます。「プロファイル → 自動バックアップ…」からワンクリックで戻せます
  • ✈ X-Plane 11 / 12：ライト、着陸装置、フラップ、パーキングブレーキ、オートパイロットのボタン（ランプが X-Plane での状態を表示）と、速度、高度、昇降率、機首方位、燃料のメーター。既製のレイアウト：フライト
  • 💻 複数のパソコン：スマホはペアリングしたすべての PC を記憶します。スマホの ⋯ → パソコン で切り替えられます
  • 🏎 レース用ダッシュボード：Forza Horizon / Motorsport、F1 23-25、BeamNG、Assetto Corsa のギア、シフトランプ、ラップタイム、順位、燃料をスマホに全画面表示。既製のレイアウト：レースゲーム
  • 📦 プロファイルギャラリー：他の人が共有した既製のプロファイルを「プロファイル → プロファイルギャラリー…」からワンクリックでインポート
  • ✨ この「新機能」ウィンドウ：更新後に変わった点を表示します

過去のバージョンとすべてのファイル：GitHub のリリースページ。
