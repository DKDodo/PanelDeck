Neuigkeiten

Was sich in jeder Version geändert hat. Das Programm und die Handy-App finden neue Versionen von selbst.

Version 0.16.2

  • 🧪 Noch nicht im echten Einsatz getestete Funktionen sind jetzt „Beta“: Twitch, Stream-Deck-Import, der Discord-Einrichtungsassistent und Vibrationswarnungen erscheinen, wenn Einstellungen → Experimentelle Funktionen (Beta) an ist. Deine vorhandenen Tasten funktionieren weiter
  • 🔒 Profilgalerie und Elgato Key Light sind „demnächst“ verfügbar, bis sie getestet sind
  • 🛠 Plugins: Das Leerzeichen vor und nach einem Live-Wert bleibt jetzt erhalten (zum Beispiel „4.3 km/h“)

Version 0.16.1

  • ⚡ Stabilere Verbindungen: Web-Anfrage-Tasten, Twitch, Plugins und die Update-Prüfung überfluten Server nicht mehr mit wiederholten Anfragen; dieselben Infos werden kurz zwischengespeichert und ein unverändertes Layout wird nicht erneut in die Cloud hochgeladen
  • 🛠 Korrekturen: eine einzelne fehlerhafte Taste bricht nicht mehr den ganzen Stream-Deck-Import ab; Twitch-Anmeldung und Plugins gehen besser mit Netzwerkfehlern um; zweimaliges Drücken einer Twitch-Clip- / Werbe-Taste löst sie nicht mehr zweimal aus
  • 📄 Datenschutzerklärung und Nutzungsbedingungen wurden für die neuen Funktionen (Twitch, Plugins, Meeting-Mikrofon) aktualisiert: Fenster „Über“

Version 0.16.0

  • 🎨 Programm-Panels: fertige Tastenkürzel-Seiten für Photoshop, Premiere Pro, After Effects, Illustrator, DaVinci Resolve, Blender, Figma und VS Code (Profil → Fertige Layouts…). Kommt das Programm in den Vordergrund, bietet das Handy an, es einzurichten (Pro)
  • 🎙 Meeting-Mikrofon: eine Taste, die dein Mikrofon in Teams, Zoom, Meet, Webex und Slack ohne Tastenkürzel stumm- und wieder einschaltet, auch wenn das Fenster im Hintergrund ist; ein Licht am Handy zeigt den Zustand
  • 🌍 8 neue Sprachen: Russisch, Italienisch, Französisch, Niederländisch, Indonesisch, Chinesisch, Japanisch und Koreanisch (Computer und Handy)
  • 🎛 Stimmstudio (Pro): 11 neue Stimmen, darunter natürliche Frauen-, Männer-, Kinder- und Seniorenstimmen; erstelle und speichere deine eigene Stimme mit Schiebereglern; Noise Gate und Kompressor. Soundeffekte → „Stimmstudio…“
  • 📥 Importiere dein Stream-Deck-Profil: Profil → „Stream-Deck-Profil importieren…“ (Tastenkürzel, Websites, Texte, Multi-Aktionen, Ordner und OBS-Tasten)
  • 📺 Twitch (Pro): Tasten für Clips, Stream-Markierungen, Werbung, Chatnachrichten und Chatmodi; Zuschauer, Laufzeit und Follower live. Einstellungen → Livestream: Twitch
  • 🧩 Plugins: neue fertige Tasten und Live-Infos mit Plugins aus einer einzigen Datei hinzufügen. Einstellungen → Plugins

Version 0.15.3

  • 📚 Anleitungen: Schritt-für-Schritt-Anleitungen zu Einrichtung, ETS2 / ATS, OBS, Discord und Fehlerbehebung auf der Website, in 5 Sprachen. Öffne sie über das Fenster „Über“ oder unter Einstellungen → Allgemein

Version 0.15.2

  • 📖 Neues Fenster „Über“: Nutzungsbedingungen, Datenschutzerklärung und Open-Source-Lizenzen sind jetzt im Programm, ohne Internet (klicke unten links auf die Versionsangabe)

Version 0.15.1

  • 📄 Nutzungsbedingungen, Datenschutzerklärung und Open-Source-Lizenzen: unten in Einstellungen → Allgemein

Version 0.15.0

  • 🖼 Echte Logos: Tasten wie Discord, Steam, YouTube und WhatsApp zeigen das eigene Logo des Programms oder der Seite (einmalig für bestehende Tasten)
  • 📳 Vibrationswarnungen (Pro): Tempolimit, Kraftstoff und Schaden in ETS2/ATS; Überlastung, verlorene Bilder und Bitrate-Einbrüche in OBS-Streams
  • 🎮 Ohne Einrichtung: Startet ein Spiel, bietet das Handy das fertige Panel an und wechselt danach von selbst dorthin
  • 🧪 Renn- und Flugunterstützung jetzt hinter dem Schalter „Experimentelle Funktionen (Beta)“ (Einstellungen)

Version 0.14.1

  • 🎨 Die Titelleiste hat jetzt dasselbe Marineblau wie die Oberfläche: kein weißer Streifen mehr
  • 🛠 Cloud-Sicherung: alte Sicherungen werden nur auf einem frisch installierten Computer angeboten

Version 0.14.0

  • ☁ Cloud-Sicherung (Pro): Dein Layout wird verschlüsselt gespeichert; wird Windows neu installiert oder der Computer gewechselt, kommt es mit deinem Handy zurück. Einstellungen → Cloud-Sicherung

Version 0.13.3

  • ✨ Neues Aussehen: das Design Nacht und Gold. Damit die Tasten passen: Profil → „Farben an das Nacht-Design anpassen“
  • 📡 Der zweite Bildschirm öffnet sich jetzt auch über mobile Daten (Fernverbindung): niedrige Qualität, wenige Bilder pro Sekunde, 20 Minuten pro Sitzung
  • 🛠 Die automatische ETS2- / ATS-Seitenbildschirm-Einrichtung wurde entfernt: Das Spiel erstreckt sich nicht über getrennte Monitore, das Bild wurde auf den Hauptbildschirm gequetscht. Falls genutzt: Einstellungen → Spiele → „Seitenbildschirm-Einrichtung rückgängig machen…“

Version 0.13.2

  • 👈 Nach links / rechts schauen rastet mit einem Tipp ein; „🎯 Nach vorn schauen“ kehrt zur Hauptansicht zurück
  • 📱 Neue Karte „Handy als Zusatzmonitor“ auf der Seite Zweiter Bildschirm: ETS2- / ATS-Seitenbildschirm mit einem Klick

Version 0.13.1

  • 📱 Nutze das Handy als Seitenbildschirm im Spiel (ETS2 / ATS, experimentell): Einstellungen → Spiele → „Handy im Spiel als Seitenbildschirm nutzen…“
  • 🖥 Zweiter Bildschirm: neues Optionsmenü, Monitore mit Modellnamen; ein virtueller Monitor erscheint als „Handy- / Tablet-Bildschirm“
  • 🚦 Echte Kontrollleuchten-Symbole auf den Lkw-Tasten und im Dashboard; neuer Pro-Bildschirm; breiteres Raster auf Tablets

Version 0.13.0

  • 🌍 Fernverbindung: das Handy verbindet sich auch über mobile Daten oder ein anderes WLAN; kein Tailscale, keine Router-Einstellung, nichts zu installieren (Ende-zu-Ende verschlüsselt)
  • ⏱ Timer-Taste: antippen startet einen Countdown, die Restzeit steht auf der Taste; wenn die Zeit um ist, vibriert und piept das Handy und der PC spielt einen Hinweiston (fertig: Fokus 25 Min., Pause 5 Min.)
  • 💾 Automatische Sicherung: dein Layout wird täglich und vor größeren Löschungen gesichert; mit einem Klick zurück über Profil → Automatische Sicherungen…
  • ✈ X-Plane 11 / 12: Tasten für Lichter, Fahrwerk, Klappen, Parkbremse und Autopilot (ihre Lichter zeigen den Zustand in X-Plane) sowie Anzeigen für Fahrt, Höhe, Steigrate, Kurs und Treibstoff; fertiges Layout: Flug
  • 💻 Mehrere Computer: das Handy merkt sich jeden gekoppelten PC; wechsle auf dem Handy mit ⋯ → Computer
  • 🏎 Renn-Dashboard: Gang, Schaltlichter, Rundenzeiten, Position und Treibstoff im Vollbild auf dem Handy für Forza Horizon / Motorsport, F1 23-25, BeamNG und Assetto Corsa; fertiges Layout: Rennspiele
  • 📦 Profilgalerie: importiere mit einem Klick fertige Profile anderer über Profil → Profilgalerie…
  • ✨ Dieses „Neuigkeiten“-Fenster: zeigt nach einem Update, was sich geändert hat

Ältere Versionen und alle Download-Dateien: Release-Seite auf GitHub.
