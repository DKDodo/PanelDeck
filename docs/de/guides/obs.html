🎥 OBS Studio

WebSocket einschalten: Szenen, Aufnahme, Streaming und Warnungen zum Stream-Zustand.

PanelDeck verbindet sich über den eingebauten WebSocket von OBS mit OBS Studio: Szenen wechseln, aufnehmen, streamen, Clips speichern und Audioquellen steuern – alles vom Handy aus.

1. WebSocket in OBS einschalten

  1. In OBS: Werkzeuge → WebSocket-Servereinstellungen → WebSocket-Server aktivieren.
  2. Notiere dir den Port (standardmäßig 4455) und das Passwort.

2. PanelDeck verbinden

  1. Öffne im Programm Einstellungen → die Karte OBS Studio und setze das Häkchen bei OBS vom Handy steuern (Szenen, Aufnahme, Streaming, Audio).
  2. Gib als Server 127.0.0.1, als Port 4455 und das OBS-Passwort ein und klicke auf Speichern. Solange OBS geschlossen ist, versucht es das Programm alle paar Sekunden erneut.

3. Tasten hinzufügen

Wähle eine Taste und dann im OBS-Bereich der Liste Vorgefertigte Aktionen eine Aktion für Szene, Aufnahme, Stream, Clip oder Audioquelle. Aufnahme- und Streamzeit stehen direkt auf der Taste. Das fertige Layout Streamer enthält die meisten dieser Tasten schon.

Warnungen zum Stream-Zustand (Pro)

Bei Überlastung, verlorenen Bildern oder sinkender Bitrate vibriert das Handy, und oben auf dem Bildschirm erscheint ein farbiger Streifen. Zum Ausschalten entferne in der Karte Einstellungen → OBS Studio das Häkchen bei Vibrationswarnung auf dem Handy bei Stream-Problemen.
