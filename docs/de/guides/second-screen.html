🖥️ Zweiter Bildschirm und Fernverbindung

Den Monitor aufs Handy holen und unterwegs über mobile Daten verbinden.

Zweiter Bildschirm (Pro)

  1. Öffne im Programm Einstellungen → die Karte Zweiter Bildschirm und setze das Häkchen bei Zweiter Bildschirm: Monitor aufs Handy übertragen.
  2. Zur Bedienung per Berührung schalte auch Handy als Maus (Berührung) und Tastatur nutzen lassen ein.
  3. Öffne auf dem Handy ⋯ → Zweiter Bildschirm.

Mit mehreren Monitoren kannst du wählen, welcher auf dem Handy erscheint. Das Bild geht nur an dein gekoppeltes Handy und wird nicht aufgezeichnet.

Fernverbindung (mobile Daten)

  • Ohne gemeinsames WLAN verbindet sich das Handy über den Vermittlungsserver von PanelDeck. Es gibt nichts einzurichten; die Verbindung ist Ende-zu-Ende verschlüsselt, und der Server kann die Inhalte nicht sehen.
  • Über mobile Daten läuft der zweite Bildschirm in niedriger Qualität (höchstens 4 Bilder pro Sekunde), und eine Sitzung dauert höchstens 20 Minuten; du kannst sie erneut öffnen. Die App weist jedes Mal auf den Datenverbrauch hin.
  • Zum Ausschalten entferne im Programm in der Karte Einstellungen → Drahtlose Verbindung das Häkchen bei Fernverbindung: auch über mobile Daten verbinden.
Kosten für mobile Daten hängen von deinem Mobilfunkvertrag ab. Für lange Sitzungen mit dem zweiten Bildschirm nimm lieber WLAN.
