🚚 ETS2 and ATS

Install the plugin: live dashboard, warning lights and vibration alerts.

PanelDeck adds lights that show the in-game state to your buttons and a live dashboard on your phone for Euro Truck Simulator 2 and American Truck Simulator.

1. Install the plugin

  1. In the program, open Settings → the Games (ETS2 / ATS) card and click Install the plugin. A small telemetry plugin is copied to the game folder (open source, MIT).
  2. Restart the game. It shows an “advanced SDK features” notice on every start: click OK.

2. Add the ready-made panel

In the program: Profile → Ready layouts… → Truck driving (ETS2 / ATS) → Use. With Pro it's even easier: when the game starts, the phone offers the ready-made panel; accept it and the phone switches to that page every time the game starts.

3. Dashboard and alerts

  • The Dashboard button opens a full-screen dashboard on the phone: speed, speed limit, RPM, fuel, arrival time and warning lights.
  • The lights, parking brake and cruise control buttons light up with the in-game state; looking left or right locks with one tap.
  • Vibration alerts (Pro): the phone vibrates when you go over the speed limit, run low on fuel or take new damage. To turn them off, on the phone open ⋯ → Settings → Game and stream alerts.
Buttons send the game's default keys. If you changed a key in the game, select the button in the program and update its In-game key field.
