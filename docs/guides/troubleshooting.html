🛠️ Troubleshooting

Quick fixes for connection, version, ETS2, OBS and Discord issues.

The phone doesn't connect

  • Are the PC and the phone on the same Wi‑Fi? If not, the phone connects remotely over mobile data, which can take a few seconds.
  • In the program, Wireless access (Wi‑Fi) on the same network must be on (Settings → Wireless connection card).
  • If Windows Firewall asked, allow both “Private” and “Public” networks.
  • Scan the QR code again: on the phone, ⋯ → Scan QR code.
  • Lost your phone? In the program, Settings → Renew pairing key. The old pairing stops working.

“Version mismatch” warning

Update the PC program and the phone app to the same version. The program finds new versions by itself; if you don't want to wait, use Settings → Check for updates now.

Windows says it “protected your PC”

More info → Run anyway. Details and how to verify the file are in the installation guide.

ETS2 button lights don't come on

Is the plugin installed? Settings → Games (ETS2 / ATS). If it is, restart the game and click OK on the “advanced SDK features” notice.

OBS doesn't connect

Is OBS open, is its WebSocket server enabled, and are the port and password right? Details in the OBS guide.

Discord can't hear me

In Discord, choose the device shown by the Set up for Discord wizard as the input device, and run the wizard's Test step.

Still stuck?

In the program, Report a problem… creates a diagnostics package (zip); the pairing key and passwords are left out. Attach it to a new topic on the support page.
