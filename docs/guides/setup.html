📲 Setup and pairing

Install the program and the app, then pair your phone with a QR code.

PanelDeck has two parts: the Windows program and the Android app. Both should be on the same version; the program finds new versions by itself.

1. Install the program on your PC

  1. Download and run the PanelDeck installer. No administrator rights are needed.
  2. If Windows says it “protected your PC”, click More info → Run anyway. Details in the installation guide.
  3. On first start the program opens the Connect your phone wizard.

2. Install the app on your phone

  1. Scan the download code in the wizard with your phone's camera.
  2. Tap the downloaded UsbDeck.apk file.
  3. If Android asks, turn on Allow from this source, then tap Install. Developer mode is not needed.

3. Pair them (Wi‑Fi, recommended)

  1. Make sure the PC and the phone are on the same Wi‑Fi network.
  2. Open PanelDeck on the phone, tap Connect with QR code and scan the code on the PC.
  3. Tap Pair. If Windows Firewall asks, allow both “Private” and “Public” networks.

To open the wizard again later, use the ＋ Add phone button in the program's top bar.

Connecting over USB (advanced)

To connect with a cable, USB debugging must be on in the phone's Developer options. The wizard's USB section shows the steps and the live connection status.

Away from home

Once paired, the phone also connects over mobile data when there's no shared Wi‑Fi; nothing to set up, and the connection is end-to-end encrypted. Details in the second screen and remote connection guide.

For a first layout, pick Streamer, Gamer, Office or Truck driving under Profile → Ready layouts…; the real logos of your programs are added automatically.
